В деле

Листайте стрелками — и смотрите, как это выглядит.

01

GIF за секунду

Поиск GIF прямо в поле ввода: выбрали — и он уже в чате. Без сторонних клавиатур и копирования ссылок.

02

Живые эмодзи и реакции

Анимированные эмодзи прямо в тексте, реакции одним касанием, большие эмодзи без пузыря. Панель раскрывается при наведении — как в Telegram.

03

Стикеры

Наборы из Telegram по ссылке и свои — редактор сам вырежет фон. Анимированные .tgs и .webm, чёткие на любом экране.

04

Серверы и комнаты

Зажмите иконку сервера — и все комнаты и чаты под рукой. Текстовые и голосовые комнаты, роли с правами, каналы с комментариями.

05

Профиль под себя

Цвет карточки и узор из эмодзи, баннер, трек и игры. Анимированный эмодзи-статус рядом с именем и форма аватарок — от круга до квадрата.

06

Звонки

Аудио, видео и демонстрация экрана напрямую, без посредника. Объёмный звук: голоса звучат с разных сторон. На телефоне — передняя и задняя камера.

07

Данные и память

Видно, что занимает место и откуда пришло: наведите на кусок — он выедет с подписью, нажмите — покажет чаты. Лимиты и автозагрузка по типам чатов.

08

Чаты как надо

Папки и группы чатов, выделение как в Telegram, приватные чаты под паролем и доставка без интернета — по Wi-Fi и Bluetooth.

09

Что нового

После каждого обновления — короткое окно с тем, что изменилось. Не нужно — выключается в настройках.

Свой сервер

Ретранслятор — ваш.

Aquamarine подключается к любому ретранслятору по адресу. Поднимите свой — на сервере, ПК или Raspberry Pi — и объедините несколько в сеть: учётные записи и копии реплицируются, клиенты сами переходят на живой узел.

1

Запустите ретранслятор

Одной командой в Docker — на Windows, macOS и Linux одинаково — или одним файлом без зависимостей. Для HTTPS поставьте перед ним Caddy или nginx.

2

Дайте адрес друзьям

Все вводят один адрес сервера при входе — IP в локальной сети или публичное имя.

3

Общайтесь

Сервер только пересылает запечатанные конверты. Прочитать их он не может.

Docker: как поставить и запустить Развёртывание и настройка

# relay in Docker: Windows, macOS, Linux docker run -d --name aquamarine-server \ --restart unless-stopped -p 7777:7777 \ -v aquamarine-data:/data \ -e AQUA_ADMIN_TOKEN=your-panel-password \ ghcr.io/applememestm-pixel/aquamarine-server # or one binary AQUA_LISTEN=0.0.0.0:7777 ./aqua-server-linux-x64 # HTTPS in front (Caddyfile) relay.example.org { reverse_proxy 127.0.0.1:7777 } # a network of relays AQUA_FED_SECRET=… AQUA_FED_PEERS=https://r2.example.org \ ./aqua-server-linux-x64 # or build from source cargo build --release -p aqua-server
Боты

Боты из Telegram работают как есть.

Ретранслятор понимает Telegram Bot API: укажите библиотеке адрес своего сервера вместо api.telegram.org — и бот на aiogram, python-telegram-bot, telegraf или grammY заработает с кнопками, вебхуками и мини-приложениями.

1

Создайте бота

«Настройки → Боты»: имя и токен. Сервер хранит только хеш токена.

2

Подключите библиотеку

Свой HTTP API или слой Telegram — /bot<token>/<method>.

3

Или без кода

aquabot run — готовый ИИ-бот на локальной модели; aqua-console.py — чат в терминале.

Руководство по ботам HTTP API

# aiogram 3 — the relay instead of api.telegram.org bot = Bot(TOKEN, session=AiohttpSession( api=TelegramAPIServer.from_base("https://relay.example.org"))) # or the native API GET /v1/bot/updates?after=0&timeout=25 POST /v1/bot/send {"to":"alice","text":"hi"} # header: Authorization: Bot aqbot_… # an AI bot on a local model, no code pip install "git+…/aquamarine#subdirectory=sdk/python" aquabot run --llm ollama:llama3.1

Почему нет веб-версии

Вкладка браузера не может надёжно хранить ваши ключи: любую загруженную страницу можно подменить, и закрытые ключи оказались бы внутри неё. Поэтому Aquamarine — приложение: ключи создаются и хранятся на устройстве в зашифрованном хранилище. Этот сайт — только парадный вход: здесь скачивают приложение, но никогда не входят в аккаунт.
