# Aquamarine 1.20.1-9

## Исправлено

- **Истории пропадали через пару часов** с ошибкой «Не удалось загрузить историю… 404». Сервер при перезапуске или самообновлении очищает кэш файлов — вместе с ним уходили и видео (и большие фото) из историй, которым ещё жить и жить. Теперь сервер хранит файлы историй отдельно, до конца их жизни. А если файл всё-таки пропал (старый сервер), приложение автора само вернёт его на сервер, как только будет в сети — у всех, кто уже видит историю, она снова откроется.
- **«1 ответ» висел под каждым стикером**, хотя ответили на один. Ответ привязывался к сообщению по тексту цитаты, а у всех стикеров она одинаковая («Стикер») — то же было с одинаковыми сообщениями вроде «ок». Теперь ответ считается только у того сообщения, на которое отвечали, и нажатие на цитату ведёт к нему.
- **Обновление «ещё не готово» по полчаса.** Новая версия для Windows, Linux и Android ждала, пока соберётся самая медленная сборка (для Mac на Intel). Теперь каждая сборка доступна для обновления сразу, как готова.
