Дополнения

Небольшие дополнения на JavaScript: свои команды /имя, кнопки в меню 📎, обработка того, что вы отправляете. Каждое работает в изолированной песочнице — без доступа к ключам, файлам и сети (кроме адресов, которые вы разрешили при установке). Список собирается сам из репозиториев авторов на GitHub.

Как установить

  1. Нажмите «Скачать .js» у дополнения.
  2. В Aquamarine: Настройки → Экспериментальное → Плагины, включите плагины.
  3. Установить из файла… и выберите скачанный файл.

Ставьте только то, чему доверяете: плагин видит текст сообщений, которые ему передают.

Как выложить своё

  1. Публичный репозиторий на GitHub с файлом .js и заголовком // @name, // @version, // @author, // @description.
  2. Добавьте репозиторию тему aquamarine-plugin (About → ⚙ → Topics).
  3. Через несколько часов дополнение появится здесь само. Обновления подтягиваются так же.
