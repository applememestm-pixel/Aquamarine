# Дополнения

Плагины из этой папки и из любых публичных репозиториев GitHub с темой **`aquamarine-plugin`** попадают в каталог на сайте ([addons.html](https://applememestm-pixel.github.io/Aquamarine/addons.html)) — сами, раз в 6 часов (`tools/addons_feed.py`, `pages.yml`).

Как выложить своё дополнение:

1. Публичный репозиторий на GitHub, в нём файл `.js` с заголовком (`// @name`, `// @version`, `// @author`, `// @description`, при необходимости `// @connect`) — см. [docs/plugins.md](../docs/plugins.md).
2. В настройках репозитория (About → ⚙ → Topics) добавить тему `aquamarine-plugin`.
3. Всё. Файл без `// @name` в каталог не берётся; форки не берутся; файлы больше 256 КБ — тоже.

Установить: скачать `.js` со страницы каталога → **Настройки → Экспериментальное → Плагины → Установить из файла…**
