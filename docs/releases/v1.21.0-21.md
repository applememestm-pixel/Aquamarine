# Aquamarine 1.21.0-21

- На телефоне истории можно открыть из шапки списка чатов. Между авторами можно листать вбок или по вертикали, как выбрано в настройках. Следующая история подгружается заранее, а после ошибки загрузку можно повторить.
- На ПК при наведении на сообщение рядом появляется кнопка быстрых реакций. Наведи на неё, чтобы выбрать реакцию.
- В группах и каналах, где доступен выбор автора, нажми на аватар рядом с полем ввода. Выбери свой аккаунт, группу или канал и нажми «Готово».
- На телефоне меню чатов открывается сбоку. На компьютере кнопка нового чата теперь внизу списка.
- Установленные Telegram-наборы и недавние стикеры синхронизируются между устройствами одного аккаунта.
- На Android приложение сохраняет имена файлов из системного выбора. Фото и видео можно открыть перед отправкой, а вложения из чата сохранить в общие «Загрузки».
- У уведомлений Android появился монохромный значок. Приложение больше не дублирует фоновыми уведомлениями отправленные тобой сообщения.
- В уведомлении есть «Отметить прочитанным» и «Ответить». На Android в личном чате можно ответить прямо из уведомления. На ПК кнопка открывает поле ввода чата.
- Защищённые чаты скрывают имя и текст в уведомлениях и виджете.
- Локальный пароль можно отключить в «Настройки → Приватность → Код-пароль».
- Для знакомства по Bluetooth на Android телефон с QR сначала готовится к приёму соединения. Второй телефон дожидается окончания поиска устройств. Исправлено разрешение, нужное для выбора сети Wi‑Fi без интернета.
- Владелец может перевыпустить токен уже существующего бота даже при заполненной квоте.
- Если на исходном устройстве сохранились старые файлы из «Избранного», приложение загрузит их при подключении и обновит существующие сообщения на остальных устройствах.
- На ПК «Музыка» занимает основную область окна. У действий воспроизведения, перемешивания и отправки единый набор иконок, а винил плавно меняет частоту вращения вместе со скоростью трека.
