# Aquamarine 1.21.0-23

Выпуск безопасности. Обновитесь: серверы 1.21.0-23 не впускают приложения старее этой версии.

- Вход на сервер теперь требует доказать владение ключом шифрования аккаунта. Раньше, зная открытый ключ человека, можно было получить доступ к его аккаунту.
- Коды подтверждения из письма хранятся в зашифрованном виде и работают один раз. После пяти неверных попыток код перестаёт действовать. Запросить новый код можно не чаще раза в 30 секунд и не больше десяти раз в час.
- Сервер без почты больше не показывает код подтверждения в приложении. Код видит только владелец сервера в панели. Прежнее поведение включается явной настройкой `AQUA_DEV_CODES=1`.
- Сервер не запускается, если не может открыть базу аккаунтов. Раньше он работал без сохранения, и после перезапуска все аккаунты пропадали.
- Ссылка «Это я» в письме ведёт только на адрес самого сервера.
- Вход по пропуску с другого сервера сети больше не может заменить ключ уже существующего аккаунта.
- В группах с комнатами у каждой комнаты свои закрепления. Закрепить можно до десяти сообщений; нажатие на полосу закрепа переходит к следующему.
- Сервер ограничивает очереди и число соединений одного устройства и не расходует одноразовые ключи шифрования по запросам без входа.
