# Aquamarine 1.1.0-5

## Одинаковые чаты на всех устройствах

- Телефон и компьютер теперь сами выравнивают переписку. Ничего нажимать не нужно.
- Новое устройство получает всю историю с остальных, а не начинает с пустого списка.
- Сообщение, которое дошло только до одного устройства (например, собеседник со старой версией приложения пишет только на основное), появится и на других, на своём месте и без повторов.
- Чат или сообщение, удалённые на одном устройстве, удаляются и на остальных, а не возвращаются обратно.
- Всё это идёт зашифрованным: сервер видит только файл, который не может прочитать. Ключи между устройствами по-прежнему не передаются.

Выравнивание происходит через несколько секунд после подключения и потом каждые несколько минут. Оба устройства должны быть обновлены до 1.1.0-5.
