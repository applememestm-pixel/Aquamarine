# Aquamarine 1.20.1-3

## Добавлено

- **Звёзды.** Официальная звезда Aquamarine и восемь уровней звезды для тех, кто поддерживает проект на Boosty. Их выдаёт только команда Aquamarine, и подделать их нельзя: каждое приложение проверяет подпись само. Звезда видна рядом с именем — в чатах и в профиле.
- **Белый список.** Конфиденциальность → «Кто может мне писать?»: все, только контакты или никто — и список тех, кому можно всегда. Сообщения от остальных не пропадают: они лежат в «Запросах на переписку» без уведомлений, откуда человека можно разрешить или заблокировать.
- **Очистка сервера одной кнопкой** (для владельцев серверов): Настройки → «Очистить сервер». Галочками выбирается, что стереть — все аккаунты целиком, файлы, стикеры, журнал — или только отдельные части. Настройки сервера остаются.

## Исправлено

- **Код-пароль больше нельзя обойти.** Раньше его можно было снять, удалив папку с данными приложения на компьютере, — и все чаты открывались. Теперь он хранится в зашифрованном хранилище, и пока приложение заблокировано, оно не отдаёт ничего. После пяти неверных попыток нужно подождать. Забыли код-пароль — код придёт на почту аккаунта.
- **Связь с сервером больше не рвётся каждые несколько секунд.** Одно «непонятное» сообщение (например, от собеседника с другой версией приложения) приложение принимало за обрыв связи: переподключалось снова и снова, на главной мигало «мс» ↔ «LAN», а сообщения терялись. Теперь такое сообщение просто пропускается.
- В «Серверах вокруг» число аккаунтов считается без ботов — у серверов одной сети оно теперь совпадает.
