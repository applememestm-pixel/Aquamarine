# Aquamarine 1.1.0-3

Небольшой пре-выпуск после 1.1.0-2.

## Плавающая клавиатура ботов (экспериментально)

- **Настройки → Экспериментальное → Плавающая клавиатура бота**: кнопки бота отрываются от поля ввода и висят над чатом.
- Их можно таскать за полоску сверху и менять размер за уголок или двумя пальцами.
- Двойное нажатие на полоску возвращает обычный размер. ✕ прячет клавиатуру, вернуть её можно кнопкой ⌨ у поля ввода.
- Место и размер запоминаются.

## Нижняя панель

- Основная нижняя панель с вкладками снова такая, как была, без настроек. Настраивается только панель в чате: меню 📎 (Настройки → Настройки чатов).
