# Aquamarine 1.1.0

Крупный выпуск. Сюда вошло всё из пре-выпусков [1.0.61](v1.0.61.md) и [1.0.62](v1.0.62.md): докачка обновлений, уведомления, код-пароль, «Новое сообщение», QR-коды, цвет карточки профиля, отпечаток пальца, комнаты по зажатию иконки сервера, «Данные и память», папка данных сервера, трей и автозапуск. Ниже — что нового сверх них.

## Новое

### Что нового

- После каждого обновления появляется это окно — на ПК и на телефоне.
- Не нужно — выключается в **Настройки → Дополнительно → Что нового**.
- Там же его можно открыть снова.

### Эмодзи-статус

- Один эмодзи рядом с именем, можно анимированный — из набора реакций сервера или своих наборов эмодзи.
- Его видно в профиле, в списке чатов, в заголовке чата и под своим именем.
- Ставится в редакторе профиля: «Эмодзи рядом с именем». Кнопка «—» убирает его.
- Сервер разрешает менять статус не чаще 30 раз в час.

### Форма аватарок

- **Настройки → Дополнительно → Углы аватарок**: три ползунка от круга до квадрата.
- Отдельно для людей, для групп и серверов, для каналов.

### Данные и память

- Наведите на кусок круга — он выедет и покажет подпись с размером.
- Нажмите на кусок — появится список чатов, откуда пришли эти файлы.
- Рядом второй круг: сколько отправили вы и куда.

### Поле ввода и стикеры

- Кнопка эмодзи и стикеров теперь внутри поля, справа, рядом с отправкой — как в Telegram.
- На ПК панель раскрывается при наведении.
- Кнопка отправки — бумажный самолётик вместо стрелки.
- Панель стикеров:
  - шире, с крупными ячейками и вкладками;
  - анимированные стикеры рисуются в двойном разрешении и больше не выглядят мыльными.

### Сервер в Docker

Свой сервер теперь поднимается одной командой — собирать ничего не нужно:

```bash
docker run -d --name aquamarine-server --restart unless-stopped -p 7777:7777 \
  -v aquamarine-data:/data -e AQUA_ADMIN_TOKEN=ваш-пароль-для-панели \
  ghcr.io/applememestm-pixel/aquamarine-server:latest
```

- Образ есть для x86-64 и ARM64 (Raspberry Pi 4/5 с 64-битной системой).
- Как поставить сам Docker на Windows, macOS и любой Linux, как обновить сервер и сделать резервную копию — [инструкция](https://github.com/applememestm-pixel/Aquamarine/blob/main/docs/docker.md). Она же есть на сайте в документации.

## Исправлено

- **Сборка APK** падала: метод сворачивания окна есть только на ПК.
- **Lichess в браузере** показывался как «Слушает Spotify».
- **Кнопка комментариев** под постом была шире самого поста, фото или кружка.
- **Дубли реакций.** Реакции на служебном `[status:v1]` дублировались, потому что дублировалось само сообщение. Такие сообщения убираются при запуске (с 1.0.62) — вместе с ними уходят и дубли.

- **Тур — карусель.** Стрелки по бокам, точки, клавиши ←/→, свайп; листается сам, пока его не трогают. Девять слайдов: GIF, эмодзи, стикеры, серверы и комнаты, профиль, звонки, память, чаты, «Что нового».
- **Настоящие картинки:**

  - аватарки — DiceBear Lorelei, CC0;
  - GIF — Wikimedia Commons.
- **Ваши наборы.** `tools/site-packs.sh` кладёт на сайт стикеры и эмодзи из наборов, которые уже скачал сервер.
- **Контакты в подвале:** Telegram, группа, X, почта.

## Совместимость

- Эмодзи-статус хранится в карточке профиля (`extra.es`). Старые версии его просто не показывают.
- Сервер 1.1.0 проверяет статус и ограничивает частоту смены. Старый сервер сохранит его как есть.
- Нумерация. Пре-выпуски после 1.1.0 называются `1.1.0-1`, `1.1.0-2`…, следующий полноценный выпуск — `1.1.1`. Приложение 1.0.6x сравнивает такие номера правильно.
