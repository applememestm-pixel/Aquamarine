# Aquamarine 1.2.0-4

Приватные серверы с общими никами, связь без интернета на виду, свой сервер — пошагово.

## Одно @имя — один человек везде

- Приватный (соло) сервер теперь можно подключить к сети **«ради имён»**. Он остаётся сам по себе: его люди общаются только между собой, а сеть их не видит и не находит. Наружу уходят только ID аккаунтов и @имена.
- Взамен @имя, занятое в сети, нельзя занять на приватном сервере — и наоборот. Если двое всё же взяли одно имя одновременно, оно остаётся у того, кто зарегистрировался раньше.

## Вход на приватный сервер

- Администратор приватного сервера выбирает, кого пускать:
  - конкретное `@имя`;
  - всех с какого-то сервера сети — `*@сервер`;
  - конкретного человека с конкретного сервера — `@имя@сервер`;
  - или по коду и QR-приглашению, как раньше.
- Чтобы показать, что ты с такого-то сервера, сделай **пропуск**: «Настройки → Аккаунт и сервер → Пропуск на приватный сервер». Вставь его в окне регистрации приватного сервера. Пропуск работает один раз и 10 минут.

## Для владельцев серверов

- Панель → «Федерация» → в режиме «Один» появилось «Вступить ради имён» — вставь туда приглашение `aquafed:` от любого сервера сети.
- Обнови и сам сервер, и серверы сети: реестр имён работает между серверами 1.2.0-4 и новее.

## Без интернета

- Сообщение, которое дошло по **Bluetooth** или по **той же Wi-Fi** без сервера, помечено **BT** или **LAN** рядом со временем.
- Пропал интернет, но доставка рядом готова — на главной вместо пинга в мс горит **BT** / **LAN** «рядом».
- В шапке чата видно **BT** / **LAN**, если вы с собеседником только что обменялись сообщениями напрямую.
- «Без интернета» вернулся в обычные настройки.
- Ограничения честно: работает только напрямую между двумя устройствами рядом (Bluetooth — около 10 м), только с теми, с кем уже переписывались через сервер, звонки так не ходят, на iPhone и Mac — только по Wi-Fi.

## Свой сервер — пошагово

- Новая инструкция «Свой сервер: пошагово» — на сайте и по ссылке из «Сервер на устройстве».
- Внутри: как запустить сервер, как понять, есть ли белый IP, где пробросить порт на Keenetic, TP-Link, ASUS, Xiaomi, Huawei, D-Link, MikroTik и роутерах провайдеров, как открыть брандмауэр, что делать, если IP меняется.
- А если белого IP нет, проброс невозможен — там же расписано, какие есть пути: только своя Wi-Fi, без интернета, виртуальная сеть, белый IP у провайдера, VPS, туннель.
