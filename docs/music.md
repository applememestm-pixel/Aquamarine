# Музыка: Navidrome

> Часть [технической документации](README.md). С версии 1.2.11.

Aquamarine умеет играть музыку из [Navidrome](https://www.navidrome.org/) — или любого сервера с Subsonic API (Airsonic, Gonic, Funkwhale…). Подключить можно два источника, и оба сразу:

- **Navidrome сервера** — его подключает владелец Aquamarine Server, и музыка появляется у всех, кто вошёл на этот сервер;
- **свой Navidrome** — адрес, логин и пароль вводит сам человек в приложении.

## Владельцу сервера

**Aquamarine Server → Музыка** (или веб-панель `/admin` → Music): адрес Navidrome, логин и пароль, кнопка «Проверить». Без приложения — переменные окружения:

| Переменная | Что это |
|---|---|
| `AQUA_NAVIDROME_URL` | Адрес, например `http://192.168.1.10:4533` |
| `AQUA_NAVIDROME_USER`, `AQUA_NAVIDROME_PASSWORD` | Учётная запись Navidrome (лучше отдельная, без прав администратора) |
| `AQUA_MUSIC_BOT` | Имя встроенного бота (по умолчанию `music`) |
| `AQUA_MUSIC_BOT_ENABLED` | `0` — без бота |

Настройки из панели хранятся в `aqua-navidrome.json` рядом с базой.

Как это работает:

- ретранслятор сам входит в Navidrome (Subsonic token auth: `md5(пароль + соль)`), логин и пароль **никогда не уходят людям**;
- через сервер можно только читать: поиск, альбомы, исполнители, плейлисты, избранное, обложки, прослушивание и скачивание. Изменить или удалить ничего нельзя;
- звук и файлы идут **насквозь, кусками**, с поддержкой `Range` (перемотка). На сервере ничего не сохраняется и не кэшируется;
- доступ — только вошедшим людям (сеансовый токен).

| Метод | Путь | Что |
|---|---|---|
| `GET` | `/v1/music` | `{ enabled, tag, bot }` |
| `GET` | `/v1/music/rest/{method}` | Subsonic-вызов из списка для чтения, ответ без обёртки `subsonic-response` |
| `GET` | `/v1/music/stream/{id}` | Поток (`maxBitRate`, `format`, `timeOffset`) |
| `GET` | `/v1/music/download/{id}` | Исходный файл |
| `GET` | `/v1/music/cover/{id}?size=` | Обложка |
| `GET`/`POST` | `/v1/admin/music`, `POST /v1/admin/music/test` | Настройки и проверка (админ-токен) |

### Бот @music

С включённым ботом сервер сам заводит учётную запись `@music`. Ей пишут название песни, альбома или исполнителя — она отвечает карточками треков. `/random` — случайные песни, `/new` — новые альбомы. Кнопка «Player» в чате с ботом открывает музыкальную страницу приложения. Чат с ботом, как и с любым ботом, не шифруется сквозным шифрованием.

## В приложении

**Настройки → Музыка** (или «Экспериментальное → Плагины → Navidrome»): включить дополнение, подключить свой Navidrome. Пароль хранится в зашифрованном хранилище устройства (`music_own`) и уходит только в ваш Navidrome — не на сервер Aquamarine.

После включения:

- **«Музыка»** — вкладка в нижней панели на телефоне и пункт в меню 📎 (на всех устройствах): поиск, новые и частые альбомы, плейлисты, избранное, страницы альбома, исполнителя и плейлиста;
- **плеер** — тот же, что и для музыки из чатов: верхняя полоса и большой плеер, очередь, повтор, перемешивание, системные кнопки управления (Media Session);
- **скачать** — кнопка ⬇ у трека: файл ложится в «Загрузки/Aquamarine»;
- **трек в чат** — карточка `[track:v1]` с обложкой, названием и длительностью. Играет у тех, у кого есть доступ к тому же Navidrome (тот же сервер или тот же свой Navidrome — сверяется короткий тег адреса), у остальных — карточка без звука;
- **«Слушает …»** — пока играет трек из Navidrome, собеседники видят его в вашей активности (выключается в «Настройки → Музыка»);
- **слушать вместе** (личные чаты) — кнопка «👥 Вместе» на музыкальной странице отправляет в открытый чат приглашение. Собеседник жмёт «Присоединиться», и его плеер следует за вашим: трек, пауза, перемотка. Состояние идёт по зашифрованному служебному каналу (`[listen:v1]`), раз в 10 секунд и при каждом изменении.

Отметки прослушивания (scrobble) отправляются только в свой Navidrome: Navidrome сервера через Aquamarine доступен только для чтения.

## Для плагинов

Плагины могут добавить свою кнопку в меню 📎, искать и играть музыку и (с разрешения) ходить в сеть — см. [plugins.md](plugins.md).
