# Модель угроз и данные

> Часть [технической документации](README.md). Как сообщить об уязвимости — [SECURITY.md](../SECURITY.md).

## 1. Противники

| Противник | Возможности | Последствия |
|---|---|---|
| Пассивный наблюдатель сети | Чтение трафика | Видит трафик TLS к ретранслятору (если TLS используется) и трафик WebRTC (DTLS-SRTP). Содержимое недоступно |
| Оператор ретранслятора, честный, но любопытный | Чтение базы данных, журналов и памяти процесса | Получает метаданные (раздел 4). Содержимое сообщений, файлов, групп и резервных копий недоступно |
| Активный оператор ретранслятора | Подмена ответов сервера | Может подменить набор ключей при первом контакте («человек посередине»). Подмену обнаруживает только сверка отпечатка по независимому каналу ([protocol.md](protocol.md#7-проверка-собеседника)) |
| Похититель базы данных ретранслятора | Офлайн-анализ | Получает хеши PBKDF2 от производного секрета Argon2id, зашифрованные резервные копии, SHA-256 токенов ботов, хеши проверочных значений ключей восстановления и ключи запечатанных посланий (см. п. 5). Пароли, ключи копий и токены не раскрываются |
| Похититель устройства без доступа к системному хранилищу ключей | Чтение файлов | Записи хранилища зашифрованы. Настройки интерфейса и медиакэш не зашифрованы ([storage.md](storage.md)) |
| Похититель разблокированного устройства | Полный доступ к сеансу | Защищают только пароль приложения и пароли отдельных чатов |

## 2. Допущения

1. Генератор случайных чисел ОС (`OsRng`, `crypto.getRandomValues`) криптографически стоек.
2. Системное хранилище ключей (Secret Service, Keychain, Windows Credential Manager) не скомпрометировано.
3. Пользователь сверяет отпечатки ключей, если угроза активной подмены для него значима.
4. Реализации примитивов (dalek-cryptography, RustCrypto, WebCrypto) корректны.

## 3. Вне рамок защиты

- сокрытие факта общения и графа связей от оператора ретранслятора;
- защита от вредоносного ПО на устройстве;
- переписка с ботами и мини-приложениями ([bots.md](bots.md));
- передача файлов по Bluetooth (защищается средствами Bluetooth, [bluetooth.md](bluetooth.md)).

## 4. Данные, доступные ретранслятору

| Доступно | Недоступно |
|---|---|
| Имя пользователя, адрес электронной почты, отображаемое имя, «о себе», телефон (если указан), публичные поля профиля | Тексты сообщений, реакции, правки, голоса, комментарии, события, документы |
| Хеш PBKDF2 производного секрета `auth_secret`; хеш проверочного значения ключа восстановления | Пароль; ключ резервной копии; ключ восстановления |
| Открытые ключи (IK, SPK, OPK) | Закрытые ключи и состояние сеансов |
| Метаданные конвертов: отправитель, получатель, время, размер; IP-адреса подключений; время последнего подключения | Ключи, имена и типы файлов |
| Шифротексты файлов и резервных копий, их размеры и время обновления | Состав, названия, комнаты, роли, фото и правила групп и каналов |
| Медиа профиля: аватар, баннер, трек (доступ можно ограничить) | Содержимое звонков |
| Опубликованная активность («играет», «слушает»), если публикация включена | Локальная история |
| Переписка с ботами (открытый текст), данные мини-приложений | Статистика каналов (считается на устройствах админов) |
| Ключи запечатанных посланий и условия их открытия, получатель | Текст запечатанных посланий |
| Перечень импортированных наборов стикеров, поисковые запросы к каталогу игр | |

## 5. Запечатанные послания

Ключ послания хранится на ретрансляторе отправителя открыто: ретранслятор должен уметь выдать его, когда условие выполнено. Текст получатель хранит в своей переписке (зашифрованной E2EE). Поэтому прочитать послание раньше срока может только тот, у кого есть и ключ, и текст: например, оператор ретранслятора отправителя вместе с похитителем устройства получателя. Подробнее — [sealed-messages.md](sealed-messages.md).

## 6. Обращения клиента к сторонним узлам

| Узел | Условие обращения |
|---|---|
| `fonts.googleapis.com`, `fonts.gstatic.com` | Загрузка шрифтов интерфейса при запуске |
| `stun.l.google.com`, `stun.cloudflare.com` | Звонки (определение внешнего адреса) |
| Узел из ссылки в сообщении | Предпросмотр ссылок (отключается в настройках) |
| `youtube.com`, `youtube-nocookie.com`, `i.ytimg.com` | Встроенный проигрыватель и обложки YouTube |
| `telegra.ph` | Статьи telegra.ph во встроенном режиме чтения |
| Адрес мини-приложения | Мини-приложение, открытое пользователем |

Ретранслятор (не клиент) обращается к `discord.com` (каталог игр, раз в неделю), `cdn.discordapp.com` (значки игр), магазину Steam и Википедии (обложки игр), Telegram Bot API (импорт наборов). Клиент получает эти данные только от своего ретранслятора.

## 7. Известные ограничения

1. Независимый аудит кода и протокола не проводился.
2. Протокол несовместим с Signal и Matrix; постквантовой защиты нет.
3. Активный оператор ретранслятора может подменить ключи при первом контакте; для обнаружения нужна ручная сверка отпечатка.
4. Метаданные (кто, кому, когда, сколько) доступны оператору ретранслятора.
5. Каждое устройство учётной записи имеет свой ключ; собеседник видит их как отдельные ключи. История, накопленная до добавления устройства, приходит из резервной копии. Реакции, отметки о прочтении и голоса между своими устройствами не синхронизируются.
6. Групповые сообщения рассылаются попарно; стоимость отправки растёт линейно с числом участников.
7. Очередь входящих сообщений ботов хранится в памяти и теряется при перезапуске ретранслятора.
8. Резервная копия защищена паролем (Argon2id, 64 МиБ) или ключом восстановления. Оператор может перебирать слабые пароли офлайн; рекомендуется пароль не короче 12 символов.
9. Медиакэш и настройки интерфейса хранятся на устройстве без шифрования. Пароль приложения и пароли чатов защищают интерфейс, а не файлы на диске.
10. Шрифты интерфейса загружаются с Google Fonts.
11. Запечатанные послания и время последнего подключения не реплицируются федерацией: условие «если я пропаду» проверяется по подключениям к ретранслятору отправителя ([sealed-messages.md](sealed-messages.md#5-ограничения)).
12. Сборка для iOS не подписана и устанавливается только через AltStore или SideStore.
