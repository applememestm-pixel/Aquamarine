# Подключение через виртуальную сеть (NetBird, ZeroTier, Tailscale, Radmin VPN, Hamachi)

> Часть [технической документации](README.md). Запуск ретранслятора — [deployment.md](deployment.md); доступ по белому IP — [deployment.md, раздел 3a](deployment.md#3a-доступ-из-интернета-по-белому-ip).

Когда белого IP нет (провайдер даёт серый адрес, мобильный интернет, общежитие) и VPS тоже нет, ретранслятор можно открыть друзьям через виртуальную локальную сеть. Программа вроде NetBird или ZeroTier ставится на компьютер с ретранслятором и на устройства друзей; каждое получает адрес в общей сети, и приложение подключается к ретранслятору по этому адресу так, будто все в одной квартире. Роутер и провайдер при этом не трогаются: соединение пробивается само (а где не пробивается — идёт через узлы сервиса).

Сообщения и файлы зашифрованы сквозным шифрованием независимо от сети ([protocol.md](protocol.md)); виртуальная сеть добавляет ещё один слой шифрования между устройствами.

## 1. Что выбрать

| Сеть | Компьютер (Windows / macOS / Linux) | Android / iOS | Адреса | Свой сервер управления |
|---|---|---|---|---|
| [NetBird](https://netbird.io) | да / да / да | да / да | `100.x.y.z` | да, открытый код |
| [ZeroTier](https://www.zerotier.com) | да / да / да | да / да | задаются в сети, например `10.147.x.x` | да (контроллер) |
| [Tailscale](https://tailscale.com) | да / да / да | да / да | `100.x.y.z` | через Headscale |
| [Radmin VPN](https://www.radmin-vpn.com) | только Windows | нет | `26.x.y.z` | нет |
| [Hamachi](https://vpn.net) | Windows, macOS (Linux — старая версия) | нет | `25.x.y.z` | нет |

- **Есть телефоны — NetBird, ZeroTier или Tailscale.** У Radmin VPN и Hamachi нет приложений для Android и iOS: телефон в такую сеть не попадёт.
- **Только компьютеры на Windows** — подойдёт и Radmin VPN: без регистрации, сеть создаётся по имени и паролю.
- Условия бесплатных тарифов (число устройств и пользователей) сервисы меняют; смотрите их сайты.

## 2. Общая схема

1. На компьютере, где будет ретранслятор, запустите его так, чтобы он слушал все сетевые интерфейсы: `tools/aquamarine-server.sh` или `tools/Aquamarine Server.bat` (оба ставят `AQUA_LISTEN=0.0.0.0:7777`), либо вручную `AQUA_LISTEN=0.0.0.0:7777 ./aqua-server-…`. Подойдёт и встроенный сервер приложения (Настройки → «Сервер на устройстве») — он тоже слушает все интерфейсы. Значение по умолчанию `127.0.0.1:7777` принимает соединения только с этого же компьютера.
2. Поставьте выбранную программу на этот компьютер и на все устройства друзей, соберите их в одну сеть (разделы 3–7).
3. Узнайте адрес компьютера с ретранслятором **в виртуальной сети** (`100.…`, `10.147.…`, `26.…`, `25.…`).
4. Проверьте с устройства друга: в браузере откройте `http://<адрес>:7777/v1/stats` — должен прийти ответ с `"ok":true`. Если нет — раздел 8.
5. В приложении при входе или регистрации в поле «Сервер» укажите `http://<адрес>:7777`.

Порт `7777` — по умолчанию; если ретранслятор запущен на другом, подставьте его.

## 3. NetBird

1. Зарегистрируйтесь на [app.netbird.io](https://app.netbird.io) (или поднимите свой сервер управления — у NetBird открытый код).
2. Поставьте клиент на компьютер с ретранслятором и войдите:
   - Windows / macOS — установщик с сайта, затем «Connect» в значке в трее;
   - Linux — `curl -fsSL https://pkgs.netbird.io/install.sh | sh`, затем `netbird up`.
3. Друзья ставят NetBird (Android, iOS, компьютер). Удобнее всего пригласить их в свою учётную запись NetBird (Team → Users) или выдать ключ настройки (Setup Keys) — устройство с ключом войдёт в вашу сеть без отдельной учётной записи: `netbird up --setup-key <ключ>`.
4. Адрес компьютера: `netbird status` (строка `NetBird IP`) или список Peers в панели — вида `100.x.y.z`.
5. В панели в разделе Access Control политика по умолчанию разрешает всем устройствам связь со всеми. Если вы её сузили — разрешите TCP 7777 к компьютеру с ретранслятором.

## 4. ZeroTier

1. Зарегистрируйтесь в [ZeroTier Central](https://my.zerotier.com) и создайте сеть (Create A Network). Скопируйте её Network ID — 16 шестнадцатеричных символов.
2. Поставьте ZeroTier One на компьютер с ретранслятором и подключитесь к сети:
   - Windows / macOS — значок в трее → Join New Network → Network ID;
   - Linux — `curl -s https://install.zerotier.com | sudo bash`, затем `sudo zerotier-cli join <Network ID>`.
3. Друзья ставят ZeroTier One (на Android и iOS — из магазина приложений) и подключаются к той же сети по Network ID.
4. В ZeroTier Central откройте сеть и в списке Members отметьте **Auth** у каждого нового устройства — без этого оно не получит адрес (у приватной сети, по умолчанию).
5. Адрес компьютера — колонка Managed IPs в Members (например `10.147.17.5`) или `zerotier-cli listnetworks`.

## 5. Tailscale (и Headscale)

1. Поставьте Tailscale на компьютер с ретранслятором и войдите (`sudo tailscale up` на Linux, приложение — на Windows и macOS).
2. Друзьям поделитесь компьютером: в [консоли](https://login.tailscale.com/admin/machines) у машины выберите Share и отправьте ссылку — друг входит своей учётной записью и видит только её. Или пригласите их в свою сеть (tailnet).
3. Адрес — `tailscale ip -4` или колонка Addresses в консоли, вида `100.x.y.z`.
4. Без внешнего сервиса: [Headscale](https://github.com/juanfont/headscale) — открытый сервер управления, совместимый с клиентами Tailscale.

## 6. Radmin VPN (только Windows)

1. Поставьте Radmin VPN на компьютер с ретранслятором и на компьютеры друзей.
2. На своём: «Сеть → Создать сеть», задайте имя и пароль. Друзья: «Сеть → Присоединиться к сети» с этими именем и паролем.
3. Адрес — в главном окне рядом с именем компьютера, вида `26.x.y.z`.
4. Windows обычно относит адаптер Radmin VPN к «общественным» сетям, где входящие соединения закрыты, — откройте порт (раздел 8).

## 7. Hamachi

1. Поставьте Hamachi (LogMeIn) на компьютер с ретранслятором и войдите учётной записью LogMeIn.
2. «Сеть → Создать сеть», задайте идентификатор и пароль; друзья — «Сеть → Подключиться к существующей сети».
3. Адрес — вверху окна, вида `25.x.y.z`.
4. Бесплатная сеть ограничена несколькими участниками; телефоны не поддерживаются. Как и у Radmin VPN, адаптер Hamachi часто попадает в «общественные» сети Windows — откройте порт (раздел 8).

## 8. Если не подключается

- **Брандмауэр Windows.** Разрешите входящие на порт 7777 (командная строка от имени администратора):
  ```
  netsh advfirewall firewall add rule name="Aquamarine relay" dir=in action=allow protocol=TCP localport=7777
  ```
  Linux: `sudo ufw allow 7777/tcp` или `sudo firewall-cmd --add-port=7777/tcp --permanent && sudo firewall-cmd --reload`.
- **Ретранслятор слушает только себя.** В строке `aqua-server listening` при запуске должно быть `0.0.0.0:7777`, а не `127.0.0.1:7777` (раздел 2, шаг 1).
- **Проверка изнутри сети.** Пинг адреса (`ping 100.x.y.z`) проверяет саму виртуальную сеть; `http://<адрес>:7777/v1/stats` в браузере — ещё и ретранслятор с брандмауэром.
- **Один VPN на телефоне.** Android и iOS держат одновременно только одно VPN-подключение: NetBird, ZeroTier и Tailscale на телефоне сами являются VPN, поэтому другой VPN (например, для обхода блокировок) придётся выключить, пока вы в виртуальной сети. У Tailscale и NetBird есть «выходной узел» (exit node), если нужен и обход.
- **Доступ к локальной сети на Android.** Если Android спросит разрешение на доступ к устройствам в локальной сети — разрешите: без него приложение не достучится до частных адресов.
- **Адрес изменился.** В NetBird, ZeroTier и Tailscale адрес устройства постоянный; в Radmin VPN и Hamachi тоже, пока устройство в той же сети. Если всё же поменялся — укажите новый в поле «Сервер» при входе.
- **Пинг рядом с названием.** На главном экране справа от «Aquamarine» показано время ответа сервера. Через виртуальную сеть 20–80 мс — норма; сотни миллисекунд обычно значат, что прямое соединение не пробилось и трафик идёт через ретрансляционные узлы сервиса (у ZeroTier, Tailscale и NetBird это видно в статусе подключения).

## 9. Звонки

Звонки идут напрямую между устройствами (WebRTC, [calls.md](calls.md)); адреса виртуальной сети попадают в список кандидатов вместе с остальными, так что собеседники в одной виртуальной сети обычно соединяются через неё и без STUN-сервера в интернете.

## 10. Белый IP или VPS вместо виртуальной сети

Виртуальная сеть удобна для небольшого круга: каждому участнику нужно поставить программу и войти в сеть. Если людей больше или нужен вход с любого устройства без подготовки, откройте ретранслятор в интернет — по белому IP ([deployment.md, раздел 3a](deployment.md#3a-доступ-из-интернета-по-белому-ip)) или на VPS с доменом и TLS ([deployment.md](deployment.md)).
