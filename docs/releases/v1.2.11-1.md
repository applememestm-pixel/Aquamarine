# Aquamarine 1.2.11-1

## Профиль

- Твой профиль теперь **отправляется на сервер при каждом подключении**: баннер, цвет карточки и подписи, изменённые без сети или на другом сервере, больше не теряются — собеседники видят их сразу.
- Нажатие на своё имя в ответе, пересылке или упоминании открывает **твой профиль**, а не пустую карточку «контакта» с кнопками «Заблокировать».

## Окно

- Кнопки «Свернуть» и «Развернуть» снова в цветах темы; белым остаётся только крестик.

## Выпуски

- Aquamarine Server для macOS снова собирается (в 1.2.1 его не было).
