## Aquamarine 1.0.2

Ночные сборки после 1.0.1 одним выпуском: телефонный интерфейс как в новом Telegram, обновления прямо в приложении, несколько аккаунтов на одном устройстве.

### Новое
- **Обновления в приложении.** Приложение само находит новую сборку, скачивает её, сверяет SHA-256 и ставит: на Android — через системный установщик, на Windows — установщиком, на Linux заменяет AppImage, на macOS открывает dmg. Настройки → Обновления: «Каждая сборка» (nightly) или «Только выпуски». На Android обновление встаёт поверх, только если сборки подписаны одним ключом ([building.md](../building.md), раздел 4.1).
- **Несколько аккаунтов на устройстве.** Удерживайте свою аватарку слева вверху на главном экране: список аккаунтов и «Добавить аккаунт». У каждого аккаунта свои чаты; при переключении приложение перезапускается.
- **Телефоны — как новый Telegram.** Плавающая нижняя панель: Чаты, Файлы, Контакты, Настройки; недавние звонки и «Пригласить друзей» — в Контактах. Сверху аватарка, «Aquamarine» и пинг до сервера.
- **Вложения.** Лист с галереей квадратными плитками, меню альбомов (Камера, Скриншоты, Telegram…), лист тянется пальцем вверх на весь экран и вниз — закрыть; множественный выбор с номерами.
- **Эмодзи, стикеры и GIF** открываются на месте клавиатуры.
- **Оформление:** «Размер текста» теперь действительно меняет текст сообщений, чатов и поля ввода; новый «Масштаб интерфейса»; полупрозрачные меню по умолчанию прозрачнее.
- **Документация:** подключение без белого IP через NetBird, ZeroTier, Tailscale, Radmin VPN, Hamachi ([overlay-networks.md](../overlay-networks.md)).
- **Сайт:** белый хвост кометы за курсором; панель «На этой странице» прокручивается к текущему разделу; сайт доступен на aquamarinemessenger.pw.

### Исправлено
- Удержание аватарки чата открывало предпросмотр и тут же закрывало его.
- Плитки галереи во вложениях налезали друг на друга полосками.
- При переключении эмодзи / стикеры / GIF на телефоне выезжала клавиатура.
- Окна открывались с «пружиной» (сжимались, потом раздувались) — теперь плавный подъём.
- Настройки на телефоне не сдвигаются вбок: переключатели, которые не помещаются, становятся выпадающими списками.
- «Непрозрачность» меню больше не переведена как вторая «Плотность».
- Сайт на телефоне: карточки тура не торчат из-за макета телефона при прокрутке.
