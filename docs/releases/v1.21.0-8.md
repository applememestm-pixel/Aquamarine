# Aquamarine 1.21.0-8

## Исправлено

- Если на телефоне вышли из аккаунта и нажали «Добавить аккаунт», прежний аккаунт мог пропасть: вход писал, что он «живёт на другом устройстве». Теперь экран входа предлагает вернуться к нему — его ключи остались на телефоне.
- Регистрация больше не пишет «имя уже занято», когда у устройства просто уже есть аккаунт: приложение называет этот аккаунт и предлагает войти в него.
- Аккаунт, из которого вышли, больше нельзя случайно удалить из списка аккаунтов вместе с ключами — после этого в него было не войти.
- В профиле в «Все игры» рядом с каждой игрой теперь её обложка.
