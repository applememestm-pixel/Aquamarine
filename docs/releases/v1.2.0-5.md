# Aquamarine 1.2.0-5

Сервер — отдельным приложением, устройства под подписью, один аккаунт на всё.

## Aquamarine Server

- Сервер теперь **отдельное приложение** для Windows, macOS, Linux и Android. Открыл — сервер работает. В окне адреса, которые нужно дать друзьям, и панель администратора.
- На компьютере сервер живёт в трее и может запускаться вместе с системой. На Android работает и с выключенным экраном.
- Мессенджер больше не запускает сервер внутри себя. Если раньше сервер работал в мессенджере — поставь Aquamarine Server на тот же компьютер: он сам подхватит данные, все аккаунты сохранятся.

## Твои устройства — под твоей подписью

- Список твоих устройств теперь подписывают сами устройства. Собеседники шифруют сообщения только для них. Даже сервер не сможет тайком добавить к твоему аккаунту своё устройство и читать переписку.
- Потерял все старые устройства — «Настройки → Устройства → начать список заново». Собеседники увидят предупреждение, как при смене кода безопасности.

## Регистрация — один раз

- На приватный сервер своей сети входишь **своим же аккаунтом**: вставь пропуск со своего сервера — @имя и ID те же, выбирать ничего не нужно.
- Новый сервер в сети сразу знает все аккаунты: на него входишь без регистрации.

## Телефон — телефонное, компьютер — компьютерное

- На телефоне больше нет сочетаний клавиш, `/help`, «нажми и говори» и подсказок про Ctrl.
- На компьютере нет стеклянных панелей и плавающей панели вложений — даже если эти настройки пришли с телефона.
