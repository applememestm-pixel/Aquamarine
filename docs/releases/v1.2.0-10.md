# Aquamarine 1.2.0-10

## Ошибки чинятся быстрее

- Если что-то сломалось, разработчик **сразу** узнаёт об этом: приложение отправляет отчёт — что сломалось, версию и устройство. **Ваших сообщений в отчётах нет никогда.** Выключить: «Настройки → О приложении».
- Ошибки самих серверов отправляются всегда.
- Владелец сервера видит отчёты своих людей в Aquamarine Server → «Ошибки».
- Новый справочник **«Коды ошибок: что делать»** — для вас и для владельца сервера.

## Темы чата

- Как в Telegram: меню чата → **«Тема чата»**. Готовые темы — Море, Лес, Закат, Ночь, Сакура и другие — или своя: акцент, фон, цвет своих и чужих сообщений, каждое в своём раскрывающемся разделе.
- У каждого чата может быть своя тема.

## Боты

- Панель ботов стала понятной, как BotFather: список ботов → страница бота с токеном, инструкцией «Как запустить» по вкладкам и удалением.

## Стикеры на своём сервере

- В Aquamarine Server → «Стикеры» можно добавить набор по ссылке из Telegram или **загрузить свои** картинки, анимации и видео-стикеры — все на сервере сразу их увидят.
- Любой набор открывается целиком; ненужный можно удалить.

## Мелочи

- Средняя кнопка мыши снова быстро прокручивает — теперь без точки на экране.
