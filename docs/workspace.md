# Календарь, задачи и рабочее пространство

> Часть [технической документации](README.md). Реализация — `ui/src/lib/planner.ts`, `ui/src/lib/workspace.ts`.

Чат может служить рабочим пространством: события, чеклисты, общие документы и доски — это сообщения чата, а изменения расходятся управляющими сообщениями `[ctl:v1]` внутри E2EE. Ретранслятор видит только зашифрованные конверты. Состояние хранится на устройствах участников и в их зашифрованных резервных копиях.

## 1. События

```
[event:v1]{"id","title","at":<мс>,"dur"?:<мин>,"place"?,"note"?,"remind"?:[<мин до начала>…]}
```

- Участники отвечают «Иду», «Возможно», «Не иду»: `[ctl:v1]{"t":"rsvp","ev","s":"yes"|"maybe"|"no"}`; карточка показывает ответы всех.
- Напоминания — свои у каждого участника: окно со звуком (звук настраивается) за выбранное время до начала.
- Экспорт в `.ics` (iCalendar) — для системного календаря.
- У каждого чата свой календарь (кнопка «Календарь» в меню инструментов): месяц с отметками дней и список событий.
- Кнопка «Комната события» создаёт временную группу, которая закроется после события ([groups.md](groups.md#7-временные-комнаты)).

## 2. Чеклисты

```
[tasks:v1]{"id","title","items":[{"id","t"}],"need":{"mode":"all"|"k"|"pct","n"},"seq"?,"open"?}
```

- Отметка пункта — `{"t":"tick","list","item","on"}`; добавление пункта участником (если `open`) — `{"t":"task_add","list","id","text"}`.
- Условие выполнения пункта: все участники, `k` человек или `n` процентов.
- `seq` — пункты выполняются по порядку.

## 3. Общие документы

```
[doc:v1]{"id","title","body"}
```

- Редактировать может любой участник чата. Сохранение рассылает новую версию: `{"t":"doc","doc","rev","body","title"?}`; побеждает больший номер версии.
- Если кто-то сохранил версию, пока документ открыт, редактор предлагает загрузить её.
- Разметка: жирный, курсив, заголовки, списки, ссылки; предпросмотр; экспорт в `.md`.
- До 20 000 символов, заголовок до 120.

## 4. Доски

```
[board:v1]{"id","title","cols":["Сделать","В работе","Готово"],"cards":[{"id","t","c"}]}
```

- Карточки перетаскиваются между колонками или переносятся стрелками; двойной щелчок — правка.
- Изменение карточки — `{"t":"card","board","id","text"?,"col"?,"del"?,"at"}`; по каждой карточке побеждает более позднее изменение.
- До 200 карточек при создании, до 500 символов в карточке.

## 5. Из выделения

Выделенные сообщения одной кнопкой превращаются в чеклист (пункт на сообщение), документ (абзац на сообщение) или доску (карточка на сообщение).

## 6. Избранное реакцией

Реакция-«закладка» (по умолчанию ⭐, меняется в настройках) копирует сообщение в «Избранное». Другие участники видят обычную реакцию. Поиск в чате умеет отбирать сообщения по реакциям.
