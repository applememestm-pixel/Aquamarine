# Aquamarine 1.21.0-3

## Новое

- **Фильтр 16+.** Кроме откровенного 18+, сервер теперь отмечает наборы стикеров с полуобнажёнкой (бельё, купальники) как 16+. Пока «Показывать контент 16+» выключено (Настройки → Стикеры), такие наборы скрыты, а их стикеры в чатах размыты до нажатия — так же, как 18+.
- **Ответ на историю ведёт к ней.** Нажмите на цитату «История» в ответе — откроется сама история. Если она уже истекла, приложение так и скажет.

## Исправлено

- Сообщение боту больше не падает с ошибкой «fetch_bundle: server responded 404», если чат с ботом был открыт через поиск или с другого устройства.
- Наборы с откровенными названиями по-русски («пошлятина», «похабное» и т.п.) сразу считаются 18+.
