What's inside

A full messenger — nothing you'd have to give up privacy for.

Everything worth keeping from the apps you already use, rebuilt so the keys never leave your machine.

Download

Pick your platform.

Native builds for every desktop, plus an Android client. Signed releases, no store account required.

Prefer to build it yourself? Everything is open source — compile from source in a few commands. Checksums ship with every release.

Self-host

Own the relay.

Aquamarine talks to any server by address. Run the relay on your own box and your messages never touch infrastructure you don't control.

1

Start the relay

One Rust binary. Point it at a port and open it to your friends.

2

Share the address

Everyone enters the same server URL on the login screen — a LAN IP or a public host.

3

Chat end-to-end

The relay only forwards sealed envelopes. It can't read a thing.

# clone & run the relay git clone <your-repo> aquamarine cd aquamarine cargo run -p aqua-server # build the desktop client cd crates/aqua-client-ui cargo tauri build # build the Android client cargo tauri android build
Bots

Your chat, in a terminal.

aqua-console is a ready-made bot: it prints a chat in your console and sends whatever you type. Write to your bot from the app — or let friends write to it — and answer from the terminal. Room mode turns it into a tiny chat room. Pure Python 3, no installs, Linux / macOS / Windows.

1

Create a bot

In Aquamarine open Settings → Bots, pick a @name and copy its token.

2

Run the script

It asks for the token with hidden input and connects to your relay.

3

Chat

Message the bot in the app. /to <user>, /who, /room, /quit.

Download aqua-console.py

# talk through your bot from the terminal python3 aqua-console.py --server https://your-relay:8443 Bot token (aqbot_…): Connected as @mybot on https://your-relay:8443 12:04 @alice: hi there! @alice > hey! answering from the terminal # a mini chat room: everyone who writes /join python3 aqua-console.py --server … --room # your own bot: plain HTTP GET /v1/bot/updates?token=…&after=0&timeout=25 POST /v1/bot/send {"token","to","text"}

Why there's no "web version"

A browser tab can't hold your keys safely — any page you load could be swapped for a malicious one, and your private keys would live inside it. So Aquamarine stays a native app: keys are generated and sealed on your device, in an encrypted vault. This page is only a front door. It's where you get the app, never where you sign in.
