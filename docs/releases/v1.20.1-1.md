# Aquamarine 1.20.1-1

## Новое

- **Каталог дополнений на сайте.** Раздел «Дополнения» собирает плагины от авторов сам: достаточно выложить файл на GitHub и добавить репозиторию тему `aquamarine-plugin`. В приложении — Настройки → Экспериментальное → Плагины → «Каталог дополнений».
- **Видно, что пересылка запрещена.** В таком чате под шапкой — тонкая полупрозрачная полоска, как «Закреплённое сообщение».
- **Истории сверху, как в Telegram.** Потяните список чатов вниз — появится полоска историй с «Моей историей».
- **Живая камера во вложениях.** Плитка «Камера» сразу показывает, что видит камера.

## Исправлено

- **Боковая панель приложений (Xiaomi, Samsung)** больше не сдвигает приложение: свайп от края экрана теперь только для системы, а чат, если его всё же сдвинуло, возвращается на место.
- Плавающее окно и разделённый экран больше не поднимают поле ввода, будто открыта клавиатура.
- Меню чата на телефоне: сообщения больше не просвечивают сквозь пункты.
- Меню «+» в панели эмодзи: все пункты в одну строку, ровно.
- **Сообщения больше не теряются**, если вы с собеседником начали переписку почти одновременно: раньше после этого часть сообщений молча не доходила.
- Под полем ввода больше нет лишней пустой полосы на телефонах с кнопками навигации.

## Изменено

- В ⋮ над списком чатов больше нет «Новый чат / группа / сервер / канал» — они на кнопке с карандашом, без повторов.
- Нажатие на свою аватарку сразу открывает профиль — без промежуточной карточки.
