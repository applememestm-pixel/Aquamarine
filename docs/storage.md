# Хранение данных на устройстве

> Часть [технической документации](README.md).

## 1. Расположение

| ОС | Каталог данных |
|---|---|
| Linux | `~/.local/share/app.aquamarine.desktop` |
| Windows | `%APPDATA%\app.aquamarine.desktop` |
| macOS | `~/Library/Application Support/app.aquamarine.desktop` |
| Android | Внутренний каталог приложения |

Каталог переопределяется переменной `AQUA_DATA_DIR` (так на одном компьютере запускаются два независимых клиента).

## 2. Состав и защита

| Данные | Место хранения | Защита |
|---|---|---|
| Идентичность, сеансы, предварительные ключи | `vault.sqlite`: каждая запись зашифрована ChaCha20-Poly1305; AAD = `Aquamarine/Vault/v1:` ‖ ключ записи | Шифрование |
| История личных и групповых чатов, «Избранное» | Записи хранилища `hist:<id>`: JSON → DEFLATE → ChaCha20-Poly1305 | Шифрование |
| Состояние групп | Запись хранилища `groups` | Шифрование |
| Токены собственных ботов | Записи хранилища `bot_token:<имя>` | Шифрование |
| Ключи резервной копии, ключ восстановления | Записи хранилища `backup:*` | Шифрование |
| Таймеры автоудаления | Запись хранилища `autodelete:v1` | Шифрование |
| Мастер-ключ хранилища (256 бит) | Системное хранилище ключей; при его отсутствии — файл `master.key` | Средствами ОС |
| Настройки интерфейса, папки, закрепления, пароли чатов (хеши), открытые запечатанные послания, статистика каналов | Хранилище WebView (localStorage) | Нет |
| Медиакэш, стикеры, звуки, обложки игр | `media-cache/`, `stickers/`, `sounds/`, `game-covers/` | Нет |

## 3. Запись истории

Фоновый поток раз в 3 с записывает изменившиеся чаты; изменения определяются сравнением хешей. При завершении приложения запись выполняется принудительно. Файлы `saved-messages.json` и `groups.json` прежних версий переносятся в хранилище и удаляются.

Чат открывается с последних 40 сообщений; более ранние подгружаются при прокрутке вверх.

## 4. Удаление

- «Удалить у себя» — только на данном устройстве.
- «Удалить у всех» — служебное сообщение E2EE собеседникам. В группах доступно и модераторам.
- Параметр «Сохранять удалённые» (по умолчанию включён) оставляет у получателя удалённое собеседником сообщение с пометкой. Предыдущие версии отредактированных сообщений сохраняются аналогично.
- Вложения и статьи удаляются только локально.
- Таймер автоудаления удаляет сообщения с устройства автоматически ([delivery.md](delivery.md#7-автоудаление)).
