# Архитектура

> Часть [технической документации](README.md).

## 1. Компоненты

| Компонент | Каталог | Назначение |
|---|---|---|
| Протокольное ядро | `crates/aqua-core` | Ключи, X3DH, Double Ratchet, форматы конвертов (`wire.rs`), шифрование файлов. Общее для клиента и сервера; сервер использует его только для проверки подписей и форматов |
| Клиентское ядро | `crates/aqua-client-core` | Транспорт HTTP и WebSocket (в том числе через SOCKS5), зашифрованное хранилище (vault), управление предварительными ключами, резервные копии и ключ восстановления, клиент Telegram для наборов |
| Клиентское приложение | `crates/aqua-client-ui` | Команды Tauri на Rust (`src/`) и интерфейс на Svelte 5 (`ui/`): чаты, группы, история, медиа, звонки, Bluetooth, автоудаление, несколько устройств |
| Ретранслятор | `crates/aqua-server` | HTTP и WebSocket: каталог, ключи, очередь конвертов, вложения, резервные копии, боты и слой Telegram Bot API, наборы стикеров, каталог игр, запечатанные послания, федерация, панель администратора |
| Библиотека ботов | `sdk/python` | `aquabot`: боты на Python, подключение нейросетей |

## 2. Схема взаимодействия

```
 ┌──────────── устройство A ────────────┐                         ┌──────────── устройство B ────────────┐
 │ Svelte 5 (WebView) ── IPC Tauri      │                         │      IPC Tauri ── Svelte 5 (WebView) │
 │ aqua-client-ui ── aqua-client-core   │                         │   aqua-client-core ── aqua-client-ui │
 │ vault.sqlite (ChaCha20-Poly1305)     │                         │     vault.sqlite (ChaCha20-Poly1305) │
 └──────────────────┬───────────────────┘                         └───────────────────┬──────────────────┘
                    │ HTTPS + WebSocket: зашифрованные конверты                       │
                    ▼                                                                 ▼
          ┌──────────────────┐    подписанные HMAC запросы федерации   ┌──────────────────┐
          │ aqua-server  R1  │ ◄─────────────────────────────────────► │ aqua-server  R2  │
          │ SQLite: каталог, │                                         │                  │
          │ очередь, копии   │                                         │                  │
          │ aqua-blobs/      │                                         │                  │
          └──────────────────┘                                         └──────────────────┘
 Медиапоток звонков идёт напрямую между устройствами (WebRTC, DTLS-SRTP); сигнализация — внутри сеансов E2EE.
```

## 3. Клиент

### 3.1. Среда выполнения

Интерфейс исполняется в системном WebView:

| ОС | WebView |
|---|---|
| Windows | WebView2 |
| macOS, iOS | WKWebView |
| Linux | WebKitGTK 4.1 |
| Android | Android System WebView |

Криптография, ключевой материал, сеть и файловый ввод-вывод выполняются в процессе Rust. Интерфейс вызывает их командами IPC Tauri (`invoke`); список команд — `invoke_handler` в `crates/aqua-client-ui/src/lib.rs`. Права интерфейса ограничены декларацией `capabilities/default.json` (окна `main` и `chat-*`). Соответствие вызовов в интерфейсе и команд Rust проверяет `tools/check-invokes.py`.

### 3.2. Модули Rust (`crates/aqua-client-ui/src`)

| Модуль | Назначение |
|---|---|
| `commands.rs` | Сеансы, отправка и приём, группы, звонки, служебные сообщения |
| `state.rs` | Состояние приложения, модель чатов и групп, права, разбор служебных префиксов |
| `history.rs` | Запись истории в хранилище (раз в 3 с, по изменению хеша) |
| `multidev.rs` | Несколько устройств: копии своих сообщений, передача чата между устройствами |
| `autodelete.rs` | Таймеры автоудаления |
| `backups.rs` | Резервные копии, ключ восстановления, сброс пароля |
| `media.rs`, `media_server.rs` | Вложения, перекодирование, локальный сервер воспроизведения |
| `personal.rs` | Профиль, обложки и значки игр, экспорт файлов |
| `activity.rs` | Определение активности («играет», «слушает»: процессы, MPRIS, Windows Media) |
| `stickers.rs` | Наборы стикеров и эмодзи |
| `bluetooth.rs` | Передача файлов по Bluetooth (OBEX через BlueZ) |
| `windows.rs` | Отдельные окна чатов |
| `gpu.rs` | Режимы отрисовки WebKitGTK |
| `web.rs` | Предпросмотр ссылок, статьи telegra.ph, открытие внешних ссылок |

### 3.3. Интерфейс (`crates/aqua-client-ui/ui/src`)

Svelte 5 (руны), TypeScript, сборщик Vite. Состояние хранится в хранилищах Svelte (`lib/*.ts`); компоненты — в `lib/components/`. Редко используемые тяжёлые панели (настройки, редакторы фото и стикеров, статьи, панель группы) загружаются при первом открытии; их состояние открытия вынесено в `lib/panels/`.

## 4. Служебные сообщения

Все сообщения между пользователями — текст внутри сеансов E2EE. Структурированные сообщения начинаются с префикса `[имя:v1]` и JSON. Ретранслятор их не видит и не различает.

### 4.1. Хранимые (показываются в чате)

| Префикс | Содержимое |
|---|---|
| `[reply:v1]` | Ответ с цитатой |
| `[fwd:v1]` | Пересланное сообщение с автором (если отправитель разрешил ссылку на себя) |
| `[poll:v1]` | Опрос |
| `[article:v1]` | Статья (заголовок, текст, медиа, музыка) |
| `[event:v1]`, `[tasks:v1]` | Событие календаря, общий чеклист — [workspace.md](workspace.md) |
| `[doc:v1]`, `[board:v1]` | Общий документ, канбан-доска — [workspace.md](workspace.md) |
| `[cmt:v1]` | Комментарий к посту канала — [groups.md](groups.md) |
| `[capsule:v1]` | Запечатанное послание — [sealed-messages.md](sealed-messages.md) |
| `[kb:v1]` | Сообщение бота с клавиатурой — [bots.md](bots.md) |
| `[grpmsg:v1]` | Сообщение группы: `{gid, author, body}` |

### 4.2. Управляющие (не сохраняются)

| Префикс | Назначение |
|---|---|
| `[seen:v1]`, `[typing:v1]`, `[status:v1]` | Прочтение, набор текста, присутствие |
| `[react:v1]`, `[edit:v1]`, `[del:v1]` | Реакции, правки, удаления |
| `[pollvote:v1]`, `[pollclose:v1]` | Голоса и закрытие опросов |
| `[grpinfo:v1]` | Снимок состояния группы (состав, роли, настройки) с номером версии |
| `[grpself:v1]`, `[grpjoin:v1]`, `[grpleave:v1]` | Свой тег в группе, заявка на вступление, выход |
| `[grpctl:v1]` | Управляющие сообщения группы (голоса, реакции) |
| `[ctl:v1]` | Общий канал функций интерфейса: ответы на события, отметки задач, правки документов, просмотры каналов, передача чата |
| `[gcall:v1]`, `AQUA-CALL:v1:` | Сигнализация групповых и личных звонков |
| `[ttl:v1]` | Таймер автоудаления личного чата |
| `[sync:v1]` | Копия своего сообщения для своих устройств |
| `[cb:v1]`, `[wad:v1]` | Нажатие кнопки бота, данные мини-приложения (боту, открытым текстом) |

Неизвестный префикс показывается как обычный текст, поэтому старые клиенты не теряют сообщения новых версий.

## 5. Структура репозитория

```
crates/aqua-core/          протокол: ключи, X3DH, Double Ratchet, конверты, шифрование файлов
crates/aqua-client-core/   транспорт, SOCKS5, хранилище, резервные копии (словарь BIP-39)
crates/aqua-client-ui/     приложение Tauri: src/ (Rust), ui/ (Svelte 5), icons/
crates/aqua-server/        ретранслятор; tests/ — интеграционные тесты (e2e, федерация, наборы)
sdk/python/                библиотека aquabot для ботов
android/                   сценарии сборки Android
tools/                     сценарии запуска, консольный бот, проверка IPC, сборка набора реакций
docs/                      техническая документация, описания релизов
site/                      сайт проекта (GitHub Pages)
.github/                   рабочие процессы, шаблоны обращений
```
