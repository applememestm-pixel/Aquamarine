# Aquamarine 1.20.1-3

## Исправлено

- **Код-пароль больше нельзя обойти.** Раньше его можно было снять, удалив папку с данными приложения на компьютере, — и все чаты открывались. Теперь он хранится в зашифрованном хранилище, и пока приложение заблокировано, оно не отдаёт ничего. После пяти неверных попыток нужно подождать. Забыли код-пароль — код придёт на почту аккаунта.
- **Связь с сервером больше не рвётся каждые несколько секунд.** Одно «непонятное» сообщение (например, от собеседника с другой версией приложения) приложение принимало за обрыв связи: переподключалось снова и снова, на главной мигало «мс» ↔ «LAN», а сообщения терялись. Теперь такое сообщение просто пропускается.
- В «Серверах вокруг» число аккаунтов считается без ботов — у серверов одной сети оно теперь совпадает.
