# IMPLEMENTATION_ROADMAP

Порядок работ после P0 (1.21.0-23). Каждый пункт — отдельный проверяемый коммит с тестом.

## P1 — до открытой беты

1. **AQUA-SEC-007.** `GET /v1/bundle` снимает OPK только с токеном; rate limit на получение bundle.
2. **AQUA-SEC-008.** Клиент удаляет OPK после успешного `accept_initial`. Набор replay первых сообщений хранится в vault.
3. **AQUA-SEC-011.** Очереди и лимиты:
   - ограниченные каналы WS с backpressure: при переполнении сообщение остаётся в `inbox` на диске и подтверждается только после записи;
   - лимит соединений на пользователя;
   - `max_message_size`;
   - уборка по TTL для `BotLimits`, `fedtunnel`, `users`.
4. **AQUA-SEC-010.** Курсор федерации `(updated_at, id)`, сдвиг только после успеха, хранение на диске, tombstone удалений.
5. **AQUA-SEC-009.** Свои Ed25519-ключи узлов (решение владельца: делать в этом проходе):
   - подпись запросов с nonce и получателем;
   - флаг в caps;
   - переходный приём HMAC от узлов без флага, с пометкой в панели.
6. **AQUA-SEC-012.** Подпись манифеста обновлений Ed25519 с ключом, встроенным в бинарь; строгая проверка URL. Включается после того, как владелец добавит секрет `UPDATE_SIGNING_KEY`.
7. **AQUA-SEC-014.** CI:
   - push на main;
   - `permissions: contents: read`;
   - cargo audit и npm audit;
   - закрепление actions по SHA;
   - dependabot.
8. **Закрепления.** Ключ `peerId#room`, несколько закреплений, перенос старого `aqua-pins`, синхронизация своим устройствам, формат в `compat.ts::KNOWN`.
9. **Комментарии.** Привязка к id сообщения, обратная совместимость по хешу.
10. **AQUA-SEC-013.** Android Keystore для мастер-ключа (перенос файла), `BOOT_COMPLETED`, служба в `patch-project.*`.
11. **CeZeOs.**
    - CZ-SEC-002: права wiki;
    - CZ-SEC-003: rate limit, проверка MIME по сигнатуре, лимит одновременных загрузок.

## P2 — до масштабирования

- **Aquamarine.**
  - Инкрементальная выдача сообщений по IPC вместо всей истории.
  - Мемоизация производных в `ChatWindow`. Замер до и после.
  - DB worker или отдельное соединение для чтения вместо одного `Mutex<Connection>` — только после замера.
- **CeZeOs.**
  - Фильтрация приватности в SQL, JOIN и агрегаты вместо N+1.
  - Keyset-пагинация `items/next_cursor/has_more`.
  - Индексы по `EXPLAIN QUERY PLAN`.
  - Поиск FTS5.
  - Миграции `user_version`.
  - Медиа из BLOB в файловое хранилище с потоковой выдачей.
- Перечисление адресов почты (AQUA-SEC-015).

## P3 — стратегия (только документы на этом этапе)

CeZeOs ID, PQXDH / ML-KEM-768, SPQR, Key Transparency (AKD), SFU, Developer Platform, общая медиаплатформа, offline-first.
