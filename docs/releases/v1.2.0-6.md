# Aquamarine 1.2.0-6

Aquamarine Server — своё окно вместо сайта.

## Панель сервера прямо в приложении

- Вся панель администратора теперь нарисована в самом приложении Aquamarine Server — без браузера и без вшитой веб-страницы.
- **Главная**: работает ли сервер и сколько времени, кнопка «Запустить / Остановить», сколько людей в сети, аккаунтов, ботов, файлов и места. Адреса для друзей — с кнопками «Копировать» и QR: друг сканирует его в Aquamarine и сразу попадает на твой сервер.
- **Люди**: кто сейчас в сети, журнал входов и регистраций с поиском по @имени, боты, гости с других серверов.
- **Доступ**: открытый сервер или только по приглашениям, список разрешённых, приглашения с QR.
- **Сеть**: один или в сети, приглашение в сеть, вступление по приглашению, серверы вокруг.
- **Почта** (только для старых версий приложения), **Стикеры** (бот Telegram и наборы на сервере), **Настройки** (порт, папка данных, автозапуск, трей).
- При первом запуске сервер сам спрашивает, как ему работать: одному или в сети.
- На телефоне и в узком окне разделы — вкладками снизу.
