# Aquamarine 1.2.0-8

Сервер, который обновляется сам.

## Aquamarine Server

- **Автообновление.** Приложение сервера само проверяет новые версии, скачивает их, сверяет контрольную сумму и ставит. На Windows и в Linux (AppImage) — без вашего участия: сервер выключается на несколько секунд и запускается уже новым, свёрнутым в трей, если был свёрнут. На macOS и Android появляется кнопка «Обновить сейчас».
- Выключить можно в «Настройки» → «Обновления». Там же — «Проверить» и ссылка «Что нового».
- Выбор «Один / В сети» при первом запуске больше не пропускает нажатия.

Версию 1.2.0-5 (с панелью во фрейме) нужно один раз обновить вручную — скачайте `AquamarineServer-Setup.exe` из этого выпуска. Дальше сервер будет обновляться сам.
