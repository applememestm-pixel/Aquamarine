## Правила оформления

- Один документ — одна подсистема; имя файла — строчными латинскими буквами через дефис.
- В начале документа — ссылка на это оглавление и на связанные документы; в тексте — ссылки на код (`путь/к/файлу`) и методы API.
- Числа и пределы берутся из кода и меняются вместе с ним в одном коммите.
- Описания выпусков — `releases/v<версия>.md`; из них берётся текст релиза на GitHub.
