# Свой сервер: пошагово

> Часть [технической документации](README.md). Подробности для администраторов — [deployment.md](deployment.md), Docker — [docker.md](docker.md), виртуальные сети — [overlay-networks.md](overlay-networks.md).

Здесь — путь для человека, который ни разу не поднимал сервер: от «скачал» до «друзья пишут мне из другого города». Если какой-то шаг не получается, внизу каждого раздела — что делать вместо него.

## 0. Что выбрать

| Вариант | Кому подходит | Работает из интернета |
|---|---|---|
| **А. Приложение Aquamarine Server** (Windows, macOS, Linux, Android) | Проще всего: поставил — работает | Да, если пробросить порт (раздел 3) |
| **Б. Консольная программа** | Компьютер или сервер без экрана, служба | Да, если пробросить порт (раздел 3) |
| **В. Арендованный сервер (VPS)** | Нужно, чтобы работало всегда и у всех | Да, сразу — порт пробрасывать не нужно |

Сообщения шифруются на телефонах, сервер их не читает при любом варианте. Сервер видит только, кто кому пишет и когда.

## 1. Запуск

### А. Приложение Aquamarine Server

С 1.2.0-5 сервер — **отдельное приложение**, мессенджер его больше не запускает.

1. Скачайте со страницы [Releases](https://github.com/applememestm-pixel/Aquamarine/releases): Windows — `AquamarineServer-Setup.exe`, Mac — `AquamarineServer.dmg`, Linux — `AquamarineServer.AppImage` или `aquamarine-server.deb`, Android — `AquamarineServer.apk`.
2. Откройте его — сервер запускается сам. В окне видны адреса: «В этой Wi-Fi» (`http://192.168.1.23:7777` — для телефонов в той же сети), «Из интернета» (появится после проброса порта, раздел 3) и панель администратора.
3. На компьютере закрытое окно не останавливает сервер: он остаётся в трее (значок у часов). Там же — «Запускать вместе с системой». Остановить совсем — правый щелчок по значку → «Остановить сервер и выйти».
4. Данные лежат там же, где у консольного сервера (`~/Aquamarine Server` или папка, выбранная раньше), поэтому переход на приложение сохраняет все аккаунты. Сервер, который раньше работал внутри мессенджера, приложение подхватывает само. Другая папка — «Другая папка…» (взять готовые данные) или «Перенести данные в…» (скопировать).
5. На Android сервер работает и с выключенным экраном (в шторке висит уведомление). Если телефон всё же его закрывает: Настройки Android → Приложения → Aquamarine Server → Батарея → «Без ограничений».

### Б. Консольная программа

1. Скачайте `aqua-server` для своей системы со страницы [Releases](https://github.com/applememestm-pixel/Aquamarine/releases) (Windows — `aqua-server-windows-x64.exe`, Linux — `aqua-server-linux-x64`, Mac — `aqua-server-macos-arm64`).
2. Запустите так, чтобы сервер слушал не только сам компьютер (`0.0.0.0`), иначе телефоны его не увидят. Windows — PowerShell в папке с файлом (Shift + правый щелчок по папке → «Открыть окно PowerShell здесь»); если SmartScreen ругается — «Подробнее → Выполнить в любом случае»:
   ```powershell
   $env:AQUA_LISTEN="0.0.0.0:7777"; .\aqua-server-windows-x64.exe
   ```
   Linux / Mac в терминале:
   ```bash
   chmod +x aqua-server-linux-x64
   AQUA_LISTEN=0.0.0.0:7777 ./aqua-server-linux-x64
   ```
   Двойной щелчок тоже запускает сервер, но только для этого компьютера (`127.0.0.1`).
3. Сервер спросит, где хранить данные, — Enter оставляет `~/Aquamarine Server`. Потом напечатает адреса: `LAN http://192.168.x.x:7777` (для своей сети) и, если получится, `Internet http://<IP>:7777`.
4. Панель администратора — ссылка `http://127.0.0.1:7777/admin#token=…`, которую сервер печатает при запуске: откройте её в браузере на этом же компьютере. Токен в ссылке каждый раз новый; постоянный задаётся `AQUA_ADMIN_TOKEN=<пароль>`.

Есть Docker — одна команда из [docker.md](docker.md).

### В. VPS

1. Арендуйте самый дешёвый VPS с Linux (Ubuntu/Debian, 1 ядро и 1 ГБ памяти хватит на сотни людей).
2. Зайдите на него по SSH (`ssh root@<IP>`; в Windows — встроенный «Терминал» или PuTTY) и выполните команду из [docker.md](docker.md) или шаги варианта Б.
3. Откройте порт в брандмауэре VPS: `ufw allow 7777/tcp` (и в панели хостинга, если там есть свой «Firewall»/«Группы безопасности»).
4. Адрес для приложения — `http://<IP VPS>:7777`. Разделы 2–3 не нужны.

## 2. Есть ли у вас белый IP

Чтобы к серверу дома подключались снаружи, у роутера должен быть **белый** (публичный) IP-адрес.

1. Откройте настройки роутера (раздел 3.1) и найдите на главной странице **IP-адрес WAN/Интернет**.
2. Откройте [2ip.ru](https://2ip.ru) или [ifconfig.me](https://ifconfig.me) с этого же Wi-Fi.
3. **Адреса совпали** — белый IP есть, переходите к разделу 3.
4. **Не совпали**, или WAN начинается с `10.`, `100.64`–`100.127`, `172.16`–`172.31`, `192.168.` — у вас «серый» IP (провайдер прячет много абонентов за одним адресом, CGNAT). Проброс порта **не сработает**, что бы вы ни настроили. Варианты — раздел 5.

Мобильный интернет (4G/5G, раздача с телефона) почти всегда серый — сразу к разделу 5.

## 3. Проброс порта на роутере

Задача: «всё, что приходит из интернета на порт 7777, отдавать компьютеру/телефону с сервером».

### 3.1. Как зайти в роутер

1. Подключитесь к его Wi-Fi.
2. Откройте в браузере один из адресов (обычно он написан на наклейке снизу роутера): `192.168.0.1`, `192.168.1.1`, `192.168.88.1` (MikroTik), `my.keenetic.net`, `tplinkwifi.net`, `router.asus.com`, `miwifi.com`.
3. Логин и пароль — тоже на наклейке (часто `admin` / `admin`), либо те, что вы задали при настройке. Роутер провайдера — пароль бывает в договоре или у поддержки.

### 3.2. Закрепите адрес сервера

Иначе через неделю роутер выдаст устройству с сервером другой адрес, и проброс перестанет работать. В списке клиентов/DHCP найдите устройство с сервером и нажмите «Закрепить IP» / «Резервировать» / «Постоянный IP». Запомните этот адрес (например, `192.168.1.23`).

### 3.3. Само правило

Во всех роутерах правило одно и то же, отличаются только названия:

| Поле | Значение |
|---|---|
| Протокол | TCP |
| Внешний порт | 7777 |
| Внутренний IP | адрес из 3.2 |
| Внутренний порт | 7777 |

Где искать (названия меняются от прошивки к прошивке — ищите похожее):

| Роутер | Путь в меню |
|---|---|
| **Keenetic** | Сетевые правила → Переадресация → Добавить правило |
| **TP-Link** (новый интерфейс) | Дополнительные настройки → NAT переадресация → Виртуальные серверы → Добавить |
| **TP-Link** (старый, зелёный) | Переадресация → Виртуальные серверы |
| **ASUS** | Интернет → Переадресация портов → Добавить профиль |
| **Xiaomi / Redmi** | Расширенные настройки → Переадресация портов (Port forwarding) |
| **Huawei / Honor** | Дополнительные функции → NAT → Переадресация портов |
| **D-Link** | Межсетевой экран → Виртуальные серверы |
| **Роутеры провайдеров** (Ростелеком, МТС, Билайн — Sagemcom, ZTE, Huawei) | Сеть → NAT / Переадресация портов / Виртуальный сервер; если пункта нет — его открывает поддержка провайдера |
| **MikroTik** | Через терминал (Winbox → New Terminal), команды ниже |

MikroTik (замените адрес и интерфейс WAN, обычно `ether1`):

```
/ip firewall nat add chain=dstnat in-interface=ether1 protocol=tcp dst-port=7777 action=dst-nat to-addresses=192.168.88.23 to-ports=7777 comment=aquamarine
/ip firewall filter add chain=forward in-interface=ether1 protocol=tcp dst-port=7777 action=accept place-before=0 comment=aquamarine
```

**UPnP.** Если в роутере включён UPnP, некоторые программы открывают порт сами. Aquamarine этого пока не делает — правило нужно вручную.

### 3.4. Брандмауэр на компьютере

- **Windows**: при первом запуске появится окно «Разрешить доступ» — отметьте **обе** галочки (частные и публичные сети). Пропустили — Панель управления → Брандмауэр Защитника Windows → «Разрешить взаимодействие с приложением» → `aqua-server` → обе галочки. Или в PowerShell от администратора:
  ```powershell
  New-NetFirewallRule -DisplayName "Aquamarine" -Direction Inbound -Protocol TCP -LocalPort 7777 -Action Allow
  ```
- **Linux**: `sudo ufw allow 7777/tcp` или `sudo firewall-cmd --add-port=7777/tcp --permanent && sudo firewall-cmd --reload`.
- **macOS**: Системные настройки → Сеть → Брандмауэр → Параметры → `aqua-server` → «Разрешать входящие подключения».
- **Android** (сервер в приложении): ничего не нужно.

### 3.5. Проверка

- В панели администратора, в адресах сервера, есть строка «Интернет (белый IP)». Пометка «не ведёт сюда» — проброс не сработал (проверьте 3.2–3.4), включён VPN или IP серый (раздел 2).
- Или с телефона **на мобильном интернете** (Wi-Fi выключить!) откройте `http://<белый IP>:7777/v1/stats` — должна показаться строка с `"version"`.
- Изнутри своей Wi-Fi белый адрес часто не открывается — это нормально (роутеры не «заворачивают» трафик обратно). Приложение само помнит оба адреса сервера и выбирает рабочий.

### 3.6. IP меняется

У многих провайдеров белый IP меняется раз в несколько дней. Чтобы друзьям не сообщать новый адрес:

- **Keenetic**: Общие настройки → KeenDNS → бесплатное имя `<имя>.keenetic.pro`.
- **ASUS**: Интернет → DDNS → `<имя>.asuscomm.com`.
- **Любой роутер**: бесплатный DDNS (DuckDNS, No-IP) — роутер или маленькая программа обновляет запись сама.

Адрес для приложения тогда — `http://<имя>:7777`.

## 4. Подключение людей

1. В приложении у друга: окно входа → «Сервер» → вставить адрес → «Создать аккаунт».
2. Проще — QR: панель администратора → «Доступ» → «Приглашения» → QR, друг сканирует его в окне входа.
3. Хотите, чтобы заходили только свои — панель → «Доступ» → «Только по приглашениям» и правила `@ник`, `*@сервер` ([federation.md](federation.md), раздел 5).

## 5. Белого IP нет — что делать

Проброс порта невозможен. Работают такие пути, от простого к надёжному:

| Путь | Что сделать | Минусы |
|---|---|---|
| **Только своя Wi-Fi** | Ничего: адрес `http://192.168.x.x:7777` работает дома | Снаружи недоступен |
| **Без интернета вообще** | Настройки → «Без интернета»: сообщения ходят по Bluetooth и локальной сети ([bluetooth.md](bluetooth.md)) | Только рядом и только между теми, кто уже переписывался |
| **Виртуальная сеть** (Tailscale, ZeroTier, NetBird, Radmin VPN) | Все ставят одну программу и входят в одну сеть; адрес сервера — из неё ([overlay-networks.md](overlay-networks.md)) | Каждому другу нужна эта программа |
| **Белый IP у провайдера** | Заказать услугу «Статический/белый IP» (обычно 100–200 ₽ в месяц) и вернуться к разделу 3 | Платно, есть не везде |
| **VPS** | Вариант В из раздела 1 | Платно (от ~200 ₽ в месяц) |
| **Туннель** (Cloudflare Tunnel, playit.gg) | Программа на компьютере с сервером даёт ему публичный адрес | Ещё одна служба, через которую ходит трафик |

## 6. Частые ошибки

| Что видите | Причина и что делать |
|---|---|
| «Nothing answers at http://127.0.0.1…» на телефоне | `127.0.0.1` — это сам телефон. Нужен адрес компьютера из своей сети (`192.168…`) |
| Дома работает, у друга — нет | Нет проброса (раздел 3) или IP серый (раздел 2) |
| Работало, перестало | Сменился IP (раздел 3.6) или адрес устройства в сети (раздел 3.2) |
| `doesn't speak HTTPS` | Пишите адрес с `http://`, а не `https://` (HTTPS — только с доменом и TLS, [deployment.md](deployment.md), раздел 3) |
| Сервер на Android пропадает | Батарея → «Без ограничений» для Aquamarine Server (раздел 1А) |
| Провайдер или сеть режет подключения | [network.md](network.md): DNS, VPN, zapret |
