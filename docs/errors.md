# Коды ошибок: что делать

Когда что-то ломается, приложение показывает код ошибки и сразу отправляет отчёт разработчику и на ваш сервер: что сломалось, версию и устройство, без текста сообщений. Выключить отправку можно в «Настройки → О приложении». Ниже — что делать с каждым кодом: сначала **вам**, потом **тому, кто держит сервер**.

Ошибки самого сервера отправляются разработчику всегда. Админ сервера видит отчёты в Aquamarine Server → «Ошибки».

## NET-REFUSED

Сервер не принимает соединение.

- **Вам:** проверьте адрес сервера на экране входа (кнопка «Изменить»). Если сервер у друга — он, скорее всего, выключен.
- **Админу:** Aquamarine Server запущен? «Главная» → «Работает». Порт тот же, что в адресе? Сервер, запущенный двойным щелчком (консольный), слушает только этот компьютер — см. [Свой сервер](self-hosting.md).

## NET-TIMEOUT

Сервер не ответил вовремя.

- **Вам:** проверьте интернет; попробуйте выключить или включить VPN.
- **Админу:** порт не проброшен на роутере, или компьютер с сервером спит. Пошагово — [Свой сервер](self-hosting.md), [Сеть](network.md).

## NET-DNS

Имя сервера не нашлось.

- **Вам:** проверьте, нет ли опечатки в адресе. Смените DNS (1.1.1.1 или 8.8.8.8) — [Сеть](network.md).
- **Админу:** проверьте DNS-запись домена.

## NET-TLS

Не получилось установить защищённое соединение (https).

- **Вам:** если адрес начинается с `https://`, а сервер без сертификата — замените на `http://`. Часы на устройстве должны идти верно.
- **Админу:** обновите сертификат или откройте сервер по `http://` в своей сети.

## NET-OFFLINE

Нет сети.

- **Вам:** включите Wi-Fi или мобильный интернет. Рядом с друзьями можно переписываться и без интернета — по Bluetooth ([Bluetooth](bluetooth.md)).

## SRV-OLD

Приложение или сервер слишком старые друг для друга.

- **Вам:** обновите приложение («Настройки → Обновления»).
- **Админу:** обновите Aquamarine Server — он обновляется сам, если не выключено.

## SRV-5XX

Сбой на сервере.

- **Вам:** подождите минуту и повторите. Отчёт уже ушёл.
- **Админу:** посмотрите Aquamarine Server → «Ошибки» и журнал. Разработчик уже получил отчёт.

## AUTH-2FA

Нужен код двухэтапной проверки.

- **Вам:** откройте приложение-аутентификатор и введите шестизначный код. Если телефона нет — используйте ключ восстановления.

## AUTH-DEVICE

Аккаунт без двухэтапной проверки привязан к устройству, где его создали.

- **Вам:** войти с другого устройства нельзя. На старом устройстве включите двухэтапную проверку или вход через Telegram («Настройки → Конфиденциальность»), потом входите где угодно.

## AUTH-RATE

Слишком много попыток подряд.

- **Вам:** подождите 15 минут.

## TG-WEBHOOK

У Telegram-бота сервера включён вебхук: сервер не видит его сообщений.

- **Админу:** этого бота использует другая программа. Дайте серверу отдельного бота (@BotFather → `/newbot`) или уберите вебхук: `https://api.telegram.org/bot<ТОКЕН>/deleteWebhook`.

## TG-CONFLICT

Сообщения бота уже читает другая программа.

- **Админу:** скорее всего, запущены два сервера с одним токеном (консольный и Aquamarine Server) или другой скрипт. Оставьте один или дайте каждому своего бота.

## TG-TOKEN

Токен бота недействителен.

- **Админу:** токен отозван — задайте новый в Aquamarine Server → «Стикеры».

## FILE-BIG

Файл больше допустимого.

- **Вам:** сожмите видео при отправке (переключатель в окне отправки) или отправьте частями.

## MEDIA

Не удалось воспроизвести медиа.

- **Вам (Linux):** установите кодеки — приложение подскажет, какие пакеты нужны. Иначе — скачайте файл и откройте в плеере.
