# Плагины

> Часть [технической документации](README.md). Экспериментальная функция: **Настройки → Экспериментальное → Плагины**.

Плагин — один файл JavaScript. Он может добавить свои команды `/имя`, менять или отменять то, что вы отправляете, и узнавать о входящих сообщениях. Похоже на плагины exteraGram, только вместо Python — JavaScript.

## Где он работает

Каждый включённый плагин запускается в своём Web Worker (`lib/plugins.ts`):

- у него нет страницы, хранилища и ключей приложения, нет доступа к мосту Tauri;
- до запуска его кода из воркера убираются `fetch`, `XMLHttpRequest`, `WebSocket`, `EventSource`, `importScripts`, вложенные воркеры, `caches`, `BroadcastChannel`, `indexedDB`; CSP приложения (`connect-src`) и так пускает только на локальные адреса;
- с приложением он общается только сообщениями; на каждый вызов — не больше 800 мс (команде — 3 с), потом приложение идёт дальше без него.

Плагин видит текст сообщений, которые ему передают, — ставьте только те, которым доверяете.

## Заголовок

Первые строки-комментарии описывают плагин:

```js
// @name Sparkle & Mock
// @version 1.0
// @author Aquamarine
// @description /sparkle оборачивает текст в ✨
```

Плагин с тем же `@name` заменяет установленный (его сохранённые данные остаются).

## API

| Вызов | Что делает |
|---|---|
| `aqua.register({ name, ... })` | Необязательно: сообщить о себе |
| `aqua.command(имя, описание, (args, chat) => строка)` | Команда `/имя`. Появляется в подсказках поля ввода. Возвращённая строка отправляется; пустое — ничего не отправлять. Имя встроенной команды занять нельзя |
| `aqua.onSend(({ chat, text }) => строка \| false)` | Перед отправкой текста: строка — новый текст, `false` — не отправлять, ничего — без изменений. Несколько обработчиков идут по очереди |
| `aqua.onIncoming(({ chat, text }) => {})` | Пришло сообщение (только чтение) |
| `aqua.toast(текст)` | Всплывающая подсказка 🧩 |
| `aqua.storage.get(ключ)` / `aqua.storage.set(ключ, значение)` | Данные плагина, сохраняются между запусками |

Обработчики могут быть `async`.

### С версии 1.2.11

| Вызов | Что делает |
|---|---|
| `aqua.button({ id, label, icon }, ({ chat }) => {})` | Свой пункт в меню 📎. `icon` — эмодзи. Обработчик получает чат, в котором нажали |
| `aqua.music.open()` | Открыть музыкальную страницу (дополнение Navidrome, [music.md](music.md)) |
| `aqua.music.search(текст)` | Песни из подключённого Navidrome: `[{ id, title, artist, album, duration, coverArt, src }]` |
| `aqua.music.play(песня)` | Включить песню из `search` во встроенном плеере |
| `aqua.music.send(чат, песня)` | Отправить карточку трека в чат |
| `aqua.fetch(адрес, { method, headers, body })` | HTTP-запрос → `{ status, headers, body }` (текст, до 2 МБ). Только к адресам из заголовка `// @connect` |

`// @connect api.example.com, *.example.org` в заголовке перечисляет, куда плагину можно ходить. При установке приложение спрашивает разрешения; без него `aqua.fetch` отвечает ошибкой. Запрос делает приложение, не воркер: у самого плагина сети по-прежнему нет.

Вызовы `aqua.music.*` и `aqua.fetch` возвращают обещания (`Promise`).

## Пример: своя кнопка с музыкой

```js
// @name Random track
// @version 1.0
// @description 🎲 в меню 📎 — случайная песня из Navidrome прямо в чат

aqua.button({ id: "dice", label: "Random track", icon: "🎲" }, async ({ chat }) => {
  const songs = await aqua.music.search("a");
  if (!songs.length) return aqua.toast("Nothing found");
  await aqua.music.send(chat, songs[Math.floor(Math.random() * songs.length)]);
});
```

## Пример

```js
// @name Arrows
// @version 1.0
// @description "->" становится стрелкой, /shout — КАПСОМ

aqua.onSend((msg) => msg.text.replace(/->/g, "→"));
aqua.command("shout", "КАПСОМ", (args) => (args || "").toUpperCase());
```

Ещё один пример есть прямо в настройках: кнопка «Пример плагина».

## Каталог дополнений

На сайте есть каталог — [addons.html](https://applememestm-pixel.github.io/Aquamarine/addons.html). Он собирается сам (`tools/addons_feed.py` при каждой выкладке сайта и раз в 6 часов) из папки [`addons/`](../addons) этого репозитория и из **любых публичных репозиториев GitHub с темой `aquamarine-plugin`**: в каталог попадает каждый файл `.js` с заголовком `// @name` (до 20 на репозиторий, до 256 КБ; форки и архивы — нет). Чтобы выложить своё дополнение, достаточно добавить репозиторию эту тему — присылать нам ничего не нужно.

В приложении: **Настройки → Экспериментальное → Плагины → Каталог дополнений**.
