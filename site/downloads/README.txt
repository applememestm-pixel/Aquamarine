Built installers land here (build-all.bat copies them in):

  Aquamarine-Setup.exe   Windows installer (built on Windows)
  Aquamarine.dmg         macOS      (build on a Mac)
  Aquamarine.AppImage    Linux      (build on Linux)
  Aquamarine.apk         Android    (cargo tauri android build)

The website's download buttons point straight at these filenames, so once a
file is here the matching button just works. Serve the `site` folder with any
static web server (or open index.html locally).
