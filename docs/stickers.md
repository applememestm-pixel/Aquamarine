# Стикеры, эмодзи и реакции

> Часть [технической документации](README.md). Реализация — `crates/aqua-server/src/packs.rs`, `crates/aqua-client-ui/src/stickers.rs`.

## 1. Наборы Telegram

Наборы Telegram импортирует **ретранслятор** через Telegram Bot API (`getStickerSet`):

- токен бота Telegram задаёт администратор ретранслятора (переменная `AQUA_TG_BOT_TOKEN`, файл `aqua-telegram.json` или панель);
- пользователь передаёт только ссылку `t.me/addstickers/…` или `t.me/addemoji/…` (`POST /v1/packs/import`);
- ограничения импорта: до 200 элементов, до 2 МиБ на файл, 16 параллельных загрузок;
- импортированный набор хранится в `aqua-packs/` и раздаётся всем клиентам ретранслятора;
- ретранслятор периодически сверяет набор с Telegram и докачивает только новое; удалённые в Telegram элементы исчезают, порядок как в Telegram. Кнопка «↻» проверяет сразу (не чаще раза в минуту).

Поддерживаемые форматы: WebP, WebM (VP9), TGS (Lottie). TGS воспроизводится библиотекой lottie-web. Наборы Telegram помечены значком и не изменяются.

`AQUA_DEFAULT_PACKS` задаёт наборы, которые импортируются при запуске (по умолчанию — набор реакций `eltaller47`).

## 2. Свои наборы

- «Новый набор стикеров/эмодзи» в меню стикеров: добавление через редактор или файлами как есть (GIF, WebM, TGS), эмодзи для каждого стикера, порядок перетаскиванием, значок набора, переименование, удаление.
- Встроенный редактор: вырезание фона, ластик и восстановление, рисование, подписи, обводка, отмена; можно пройти по многим картинкам подряд.
- Свои наборы хранятся на устройстве (`stickers/`). Касание стикера в чате открывает весь его набор.

## 3. Эмодзи и реакции

- Пользовательские эмодзи из наборов вставляются прямо в текст (`[ce:<набор>/<файл>]`) и показываются у получателей, если их ретранслятор знает этот набор.
- Набор реакций можно встроить в сборку клиента (`tools/bundle-reactions.*`): тогда он работает без токена Telegram.
- Быстрые реакции настраиваются; реакция-«закладка» сохраняет сообщение в «Избранное» ([workspace.md](workspace.md#6-избранное-реакцией)).
