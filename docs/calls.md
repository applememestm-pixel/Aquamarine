# Звонки и голосовые комнаты

> Часть [технической документации](README.md).

## 1. Личные звонки

- Аудио- и видеозвонки идут по WebRTC напрямую между устройствами. Медиапоток защищён DTLS-SRTP (RFC 8827).
- Сигнализация (SDP, ICE, завершение) передаётся внутри сеанса E2EE сообщениями `AQUA-CALL:v1:`; ретранслятор её не видит.
- Для обхода NAT используются публичные STUN-серверы `stun.l.google.com` и `stun.cloudflare.com`. Сервер TURN пользователь задаёт сам («Настройки → Голос и видео»); по умолчанию он не задан, и за симметричным NAT звонок может не установиться.
- Звонок приходит на все устройства собеседника; когда одно отвечает или отклоняет, остальные перестают звонить.
- Во время звонка доступны камера, демонстрация экрана, выбор устройств ввода и вывода, полноэкранный и компактный режимы.

В верхней панели чата одна кнопка звонка: по нажатию — выбор «Аудиозвонок» или «Видеозвонок». Видеозвонок включает камеру после соединения.

## 2. Групповые звонки

- Схема полносвязная (mesh): каждый участник соединён с каждым. Практический предел — несколько человек с видео и около десятка с голосом.
- Сигнализация — `[gcall:v1]`: `join`, `here`, `offer`, `answer`, `ice`, `state`, `leave`. Широковещательные сигналы идут всем участникам группы, адресные — одному.
- Если два участника начали звонок одновременно, звонки сливаются: побеждает идентификатор, который меньше лексикографически.
- В канале говорят администраторы, остальные слушают («прямой эфир»).
- В супергруппах звонки живут в голосовых комнатах; комнату можно развернуть на весь экран с чатом сбоку.

## 3. Объёмный звук

В голосовых комнатах можно включить объёмный звук (кнопка в панели звонка; по умолчанию выключен).

- Голос каждого участника проходит через `PannerNode` Web Audio с моделью HRTF, поэтому собеседники звучат с разных сторон. Лучше всего — в наушниках.
- По умолчанию участники расставлены дугой перед слушателем. На карте комнаты их можно перетаскивать; расстановка запоминается для каждой комнаты.
- Акустика: «Открыто» (без отражений), «Комната» и «Зал» (синтетическая реверберация через `ConvolverNode`).
- Пока режим включён, элементы `<audio>` остаются подключёнными, но заглушены: звук идёт через Web Audio. «Заглушить всё» обнуляет общий усилитель.

Реализация — `ui/src/lib/spatial.ts`, `SpatialMap.svelte`. В WebKitGTK источник Web Audio для удалённого потока WebRTC поддерживается не во всех версиях; если со включённым режимом собеседников не слышно, режим нужно выключить.

## 4. Качество

Пресеты разрешения (720p, 1080p, 1440p, исходное) и частоты кадров (15, 30, 60) для камеры и демонстрации экрана; предпочтительный кодек (H.264 с аппаратным ускорением по умолчанию, VP9, AV1, VP8); Opus с FEC и стереозвуком. Целевой битрейт задаётся по разрешению и частоте кадров, ограничение качества браузером видно в статистике. Статистика соединения (задержка, потери, джиттер, кодек, разрешение, маршрут) показывается в окне звонка. Реализация — `ui/src/lib/rtcQuality.ts`.
