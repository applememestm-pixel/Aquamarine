# Aquamarine 1.2.0

Большой выпуск: аккаунт под защитой, одинаковые чаты на всех устройствах и всё, что накопилось с 1.1.0.

## Двухэтапная проверка — теперь у всех

- Без двухэтапной проверки аккаунт больше не работает. После обновления приложение один раз попросит её включить: отсканируй QR-код в приложении-аутентификаторе (Google Authenticator, Aegis, 2FAS, Bitwarden — любое) и введи 6 цифр.
- Сохрани **10 резервных кодов**, которые покажутся сразу. Каждый срабатывает один раз — на случай, если телефон с приложением потеряется.
- Выключить проверку нельзя. Новый телефон? **Настройки → Конфиденциальность → «Другое приложение»** перенесёт коды на него.
- Ещё там же можно **запретить вход с новых устройств** совсем.
- Если кто-то вошёл в аккаунт с нового устройства, на твоих появится окно **«Вход с нового устройства — это я / отключить»**. Пока не подтвердишь, новое устройство не получит ни чатов, ни истории.
- Потерял всё сразу? **Ключ восстановления из 24 слов** открывает аккаунт без кода.

## Чаты одинаковые везде

- Сервер хранит историю переписки, зашифрованную ключом, который есть только у твоих устройств. Сам сервер её не прочитает.
- Новое устройство получает все чаты сразу после входа, а новое сообщение или удаление доходит до остальных за пару секунд.

## Что ещё появилось с 1.1.0

- **ID аккаунта** — 10 цифр, как в Telegram: не меняется даже при смене @имени, по нему можно найти человека.
- **Личные сообщения каналу**, подпись к фото внутри сообщения, цитаты, звонки в истории чата.
- **Увеличение двумя пальцами** любого фото, видео, стикера прямо в чате; зажатый стикер можно «вести» по соседним.
- Стеклянные панели, настройка меню вложений 📎, плагины (экспериментально), виджет на Android.
- QR-коды серверов и приглашений на приватный сервер.
- Справка про DNS, VPN и zapret в «Сети и прокси».

## Старые версии больше не работают

- Сервер 1.2.0 не пускает приложения старше 1.2.0, а приложение 1.2.0 не работает со старыми серверами. **Обнови приложение на всех устройствах и сам сервер.**
- Серверы старше 1.2.0 исключаются из сети серверов: они не знают двухэтапной проверки, и через них можно было бы войти без кода.
- Владелец сервера может сделать двухэтапную проверку необязательной: панель администратора → Доступ.
