# Aquamarine 1.2.1

Большое обновление: переписка без интернета, темы чатов, обновления как в Telegram и быстрые исправления ошибок.

## Познакомиться без интернета

- **«Новое сообщение» → «Познакомиться рядом»**: один показывает QR, другой сканирует — и можно сразу переписываться по Bluetooth или через общий Wi-Fi. Без сервера и без интернета, со сквозным шифрованием.

## Чаты

- **Сообщение отправляется как в Telegram** — плавно выплывает из поля ввода. Старые сообщения больше не «подпрыгивают» при открытии чата.
- **Темы чата**: меню чата → «Тема чата». Готовые — Море, Лес, Закат, Ночь, Сакура и другие — или своя: акцент, фон, цвет своих и чужих сообщений. У каждого чата может быть своя.
- На телефоне **уведомления приходят в шторку**, даже когда приложение свёрнуто.
- Виджет на главном экране показывает, кто написал и что.
- Окно отправки фото на телефоне показывает саму фотографию и выезжает снизу.
- Светлая тема больше не красит шапку и поле ввода в серый.

## Обновления как в Telegram

- На Windows новая версия ставится **без окна установщика**: приложение закрывается на пару секунд и открывается уже обновлённым.
- **Aquamarine Server обновляется сам.**

## Ошибки чинятся быстрее

- Если что-то сломалось, разработчик **сразу** узнаёт об этом: приложение отправляет отчёт — что сломалось, версию и устройство. **Ваших сообщений в отчётах нет никогда.** Выключить: «Настройки → О приложении».
- Справочник **«Коды ошибок: что делать»** — для вас и для владельца сервера.

## Aquamarine Server

- Кнопки в окне сервера снова нажимаются, текст стал контрастнее.
- **Стикеры**: добавить набор по ссылке из Telegram или загрузить свои — все на сервере сразу их увидят; любой набор открывается целиком.
- Вкладка **«Ошибки»** — сбои приложений людей на этом сервере.

## Профиль и боты

- Светлый цвет карточки больше не превращается в серый, редактор профиля выровнен.
- Из профиля на телефоне можно выйти кнопкой «назад».
- Панель ботов стала понятной, как BotFather: список ботов → страница бота с токеном и инструкцией «Как запустить».

## Мелочи

- Средняя кнопка мыши быстро прокручивает — без точки на экране.
- Вход через Telegram объясняет, что пошло не так, если бот сервера недоступен.
- На экране входа сервер — заметная кнопка «Изменить».
- В поле @имени «@» больше не налезает на текст; «Избранное» и «Невидимка» переводятся сразу при смене языка.
