# Aquamarine 1.21.0-26

Обновления, которым можно доверять.

- Пре-выпуски ставятся только тем, у кого включён «Тестер». Раньше подменённая страница обновлений могла выдать пре-выпуск всем. Теперь это решает номер версии, а его подтверждает подпись выпуска.
- Если выключить «Тестер» после того, как пре-выпуск уже скачался, он не установится.
- Сервер, который обновляется сам, запускает ровно тот файл, который проверил по подписи. Подменить его после проверки уже нельзя: ни заменой файла, ни записью в него. Если проверенный файл запустить не удалось, сервер остаётся на своей версии.
- Сайт Aquamarine, поднятый у себя скриптом `aquamarine-site.sh`, ставится только из подписанного выпуска. Неподписанный выпуск скрипт не возьмёт.
