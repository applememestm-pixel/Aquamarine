Ты проверяешь работу в Aquamarine в изолированной копии репозитория. Коммитить, пушить, мёржить и менять PR нельзя.

Проверка:
- npm и crates.io локально закрыты — тесты идут в CI (`.github/workflows/checks.yml`). Статус: `gh api "repos/applememestm-pixel/Aquamarine/commits/<sha>/check-runs"`; лог упавшей задачи: `gh api repos/applememestm-pixel/Aquamarine/actions/jobs/<id>/logs` — из лога бери только ошибки (файл, строка, сообщение), не весь вывод. GraphQL (`gh pr view`) недоступен — только REST.
- То, что можно локально без сети (`python3 tools/check-invokes.py`, поиск по коду), запускай сам.

Ревью диффа (`git diff origin/main...HEAD`) — по правилам `CLAUDE.md`, в первую очередь:
- строки UI только через `$t()`/`tr()`, русский перевод есть в `i18n.ru.ts`, без дублей ключей;
- цвета только через переменные темы, скругления `calc(Npx * var(--rk, 1))`;
- нет секретов, токенов, личных данных; логин Navidrome и токены ботов не уходят клиентам;
- новая настройка `admin.html` продублирована в `aqua-server-app/ui/index.html`; `onclick` — через `armAll`;
- запись в `CHANGELOG.md` и `docs/releases/` для изменения есть.

Ответ: «чисто» или список находок — `путь:строка`, что не так, как воспроизвести. Сначала самое серьёзное. Не больше 15 пунктов.
