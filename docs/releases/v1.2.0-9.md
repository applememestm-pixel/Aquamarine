# Aquamarine 1.2.0-9

## Обновления как в Telegram

- На Windows новая версия ставится **без окна установщика**: приложение закрывается на пару секунд и открывается уже обновлённым.

## Aquamarine Server

- **Кнопки в окне сервера снова нажимаются** — выбор «Один / В сети», копирование адресов, QR, переключатели.

## Профиль

- Светлый цвет карточки (белый, бежевый, жёлтый) больше не превращается в серый: карточка остаётся светлой, а текст на ней — тёмным и читаемым. Тёмные и насыщенные цвета выглядят как раньше.
- Редактор профиля выровнен: обе колонки начинаются на одной линии, ползунки не переносят подписи, палитра цветов ровно по ширине.

## Вход через Telegram

- Если сервер не может получить сообщения своего бота, окно входа сразу объясняет почему — вместо бесконечного «Ждём Telegram».
- Можно открыть бота ещё раз, если Telegram не открылся.

## Мелочи

- В поле @имени при регистрации «@» больше не налезает на текст.
- «Избранное» переводится сразу при смене языка, «Невидимка» под именем — тоже.
