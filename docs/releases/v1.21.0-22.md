# Aquamarine 1.21.0-22

- Большие файлы отправляются по частям и продолжают загрузку после обрыва. Максимальный размер зависит от тарифа, до 2 ГиБ. Для некоторых MP4 плеер сначала загрузит файл целиком.
- На настроенных ретрансляторах со Stars доступны перевод и расшифровка по подтверждению. В конструкторе ботов появился редактор сценариев.
- Владение сообществом переходит после подтверждения участником. Владелец канала может привязать группу для комментариев и установить правило редактирования постов.
- Значок @ в списке чатов показывает непрочитанное упоминание или ответ. У подписанных постов видны подписи редакторов. Администраторы могут открыть сведения о правке в течение суток.
