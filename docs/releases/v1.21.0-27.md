# Aquamarine 1.21.0-27

Сообщения приходят и тогда, когда приложение закрыто, — без Google.

- Android: Настройки → Уведомления → «Пробуждение через UnifiedPush». Нужно приложение UnifiedPush, например ntfy. Когда вам пишут, сервер посылает телефону только «проснись», без текста, отправителя и чата. Телефон показывает «Новое сообщение», а сами сообщения приходят, когда вы откроете Aquamarine.
- Можно не держать постоянное подключение в фоне: ntfy держит одно соединение на все приложения.
- Сервер будит устройство не чаще раза в 20 секунд. Если за это время пришло ещё сообщение, сервер разбудит ещё раз, когда пауза кончится, — сообщение не потеряется.
- Устройство, которое вышло из аккаунта, больше не будится.
- Для админа сервера: пробуждение работает само, ничего настраивать не нужно. Адреса UnifiedPush сервер проверяет: в локальную сеть и на сам сервер он не пишет.
